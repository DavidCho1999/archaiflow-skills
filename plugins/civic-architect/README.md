# Civic Architect

A civic architect's read on a government building.

Civic architect's read on a federal / state / local government building — courthouse / library / city hall / federal building / GSA P-100 conformance / state CIP / municipal facility — surfaces the one or two things most likely to bite rather than a full audit. Returns a short risk-flagged memo and names the skill to run next. Stays in lane: judgment, not redesign or programming. Use this agent for federal / state / local government building lens; use `senior-architect` for private-sector building shell; use `higher-education-architect` for university; use `K12-architect` for K-12 (when shipped). Examples that should trigger this agent — "what would a civic architect say about this courthouse", "GSA P-100 conformance check", "city hall public-vs-back-of-house security balance", "is this library bond-funded design going to bite", "ABA / ADA dual compliance review on this federal building".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **civic-architect**.

In Claude Code:

```
/plugin install civic-architect --marketplace DavidCho1999/archaiflow-skills
```
