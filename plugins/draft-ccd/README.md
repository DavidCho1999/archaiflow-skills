# Draft CCD

Direct a change before cost and time are agreed.

Draft a Construction Change Directive (AIA G714-2017) for changes where Owner and Contractor have not agreed on Contract Sum or Contract Time. Use /draft-asi for instructions with NO change to Sum/Time; use AIA G701 Change Order once agreement is reached.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-ccd**.

In Claude Code:

```
/plugin install draft-ccd --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/draft-ccd
