# Test Energy

Check one assembly against the energy table for your zone.

Single-assembly prescriptive energy gut-check (R-value or U-factor vs IECC table by climate zone) — user pastes or authorizes fetch of operative IECC table; PASS / FAIL / MARGINAL with explicit attribution. Carries no IECC values internally.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **test-energy**.

In Claude Code:

```
/plugin install test-energy --marketplace DavidCho1999/archaiflow-skills
```
