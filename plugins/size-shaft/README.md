# Size Shaft

Add up what has to fit in a shaft, plus the room to install and reach it.

Adds up the architectural space a mechanical, electrical or plumbing shaft needs from the schedule of what runs in it: the services and their dimensions as you supply them, the clearances each needs from the others, the space to install them in the order they get installed, the access to reach anything that has to be maintained, and the rated enclosure around all of it. Reports the required clear dimension against the shaft you have drawn. Carries no duct sizes, no pipe dimensions, no clearances and no rating requirements; the services come from the engineer and the clearances from code and manufacturer data. It does not size the services themselves — `design-duct` sizes a duct run — and it does not replace the MEP engineer or the Architect of Record.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **size-shaft**.

In Claude Code:

```
/plugin install size-shaft --marketplace DavidCho1999/archaiflow-skills
```
