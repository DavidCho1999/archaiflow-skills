# Draft Bulletin

Write a cover letter for a bulletin or addendum.

Draft a CD-set bulletin or pre-bid addendum cover letter for distribution to bidders, GC, or AHJ. Use /draft-asi for in-CA architect's instructions; use /draft-ccd for changes affecting Contract Sum or Time. Bulletin = CA-phase modification; Addendum = bid-phase pre-execution document (per AIA A201 §1.1.1).

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-bulletin**.

In Claude Code:

```
/plugin install draft-bulletin --marketplace DavidCho1999/archaiflow-skills
```
