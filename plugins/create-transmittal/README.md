# Create Transmittal

Make a cover sheet for a document package.

Create a transmittal cover sheet for AEC document distribution (PDF default, NA conventions)

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **create-transmittal**.

In Claude Code:

```
/plugin install create-transmittal --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/create-transmittal
