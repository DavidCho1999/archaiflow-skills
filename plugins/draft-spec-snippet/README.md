# Draft Spec Snippet

Write a product paragraph for a spec section.

Draft a CSI MasterFormat 2020 Part 2 (Products) paragraph for a single product within a spec section. Use /explain-spec to interpret an existing CSI section; use the spec-review skill for full-spec audit; use /draft-callout for drawing-side product references.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-spec-snippet**.

In Claude Code:

```
/plugin install draft-spec-snippet --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/draft-spec-snippet
