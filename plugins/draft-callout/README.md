# Draft Callout

Write the text inside a drawing callout.

Draft drawing-callout text — the words inside or next to a callout bubble — following US National CAD Standard (NCS) conventions. Produces text only, not the bubble graphic (drafting work in Revit / AutoCAD). Use /draft-spec-snippet for spec language; use /explain-drawing for interpreting an existing callout.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-callout**.

In Claude Code:

```
/plugin install draft-callout --marketplace DavidCho1999/archaiflow-skills
```
