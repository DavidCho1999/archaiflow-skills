# Explain Bid

Separate real costs from risk-shifting in bid language.

Decode bid qualification language (AIA A101/A102/A103 + A305 + A701) — separate cost items from risk-shifting and schedule assumptions

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-bid**.

In Claude Code:

```
/plugin install explain-bid --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/explain-bid
