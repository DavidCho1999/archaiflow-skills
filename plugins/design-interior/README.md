# Design Interior

Decide what the interior has to do before detailing any part of it.

The door into interior work, and the step that is usually missing: before partitions, ceilings, millwork or finishes are drawn, establish what each space actually has to withstand, where the money should go, which spaces repeat and which get attention, and what the base building has already decided. Produces the strategy the specific skills then execute against, and hands each part off by name. Trigger on "design the interior", "interior strategy", "where do we spend on this fit-out", "what finishes for this project", "the interior feels arbitrary", "design-interior", or an interior scope with no strategy behind it. Carries no finishes, no specifications, no costs and no ratings; every requirement comes from the brief, the client's operation, or the code you quote. It details nothing itself — `design-partition`, `design-ceiling`, `design-millwork` and `schedule-builder` do that — and does not replace the interior designer or the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
