# Explain COI

Explain a certificate of insurance and what it does not prove.

Reads a certificate of insurance against the coverage a contract requires and explains, in plain English, what each line means and what the certificate does not establish: that it is evidence of a policy rather than the policy, that additional insured status depends on an endorsement the certificate only claims, and that the wording on the face of it is expressly not a modification of coverage. Checks limits, dates, named parties and the gaps that matter to a design professional. Carries no coverage requirements and no policy language; the requirement comes from the contract and the coverage from the policy. It is not insurance advice — the broker reads the policy and the insurer confirms coverage. For advice on what to carry use the `insurance-advisor` skill.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-coi**.

In Claude Code:

```
/plugin install explain-coi --marketplace DavidCho1999/archaiflow-skills
```
