# Explain Stamp

Explain what a submittal stamp commits you to.

Interpret a submittal stamp marking (A / AAN / RNR / R) and what it binds the contractor and architect to under AIA A201 §3.12

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-stamp**.

In Claude Code:

```
/plugin install explain-stamp --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/explain-stamp
