# Test Open Space

Check provided open space against what the district requires.

Checks a parcel's provided open space against the requirement in the zoning text you supply or paste, and does the part that goes wrong: applying the definition. Open space, usable open space, landscaped area, permeable area and amenity space are different terms with different rules about what counts, and a check that measures the wrong area passes on paper. Establishes which term the district uses, what its text says counts and what does not, then measures what you provided against it. Carries no ratios and no definitions; both come from the jurisdiction's published text. The other bulk topics — FAR, lot coverage, setback and height — are `/test-far`; for a full worksheet use the `zoning-summary` skill.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **test-open-space**.

In Claude Code:

```
/plugin install test-open-space --marketplace DavidCho1999/archaiflow-skills
```
