# View Analysis

Work out what each room sees, and what protects it.

Works views in both directions, because a window is two things at once: what a room looks at, and what looks back into it. Establishes what is worth seeing and whether it will still be there, what each room needs to see and what it must not, where privacy runs both ways between this building and its neighbours, and which views depend on land somebody else owns. Trigger on "view analysis", "what does this room look at", "will we still have this view", "overlooking", "privacy from the neighbours", "view-analysis", or a scheme where the windows have been placed by elevation rather than by what they see. Carries no angles, no distances and no separation requirements; overlooking rules are local text you quote and sun angles come from `shadow-study`. It does not model and does not replace the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

