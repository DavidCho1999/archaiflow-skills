# Dispute Advisor

Find the next required step and notice deadline in a dispute.

Locates a live construction dispute on the escalation ladder of the contract in force, names the next required step, the notice deadline that governs it, and the point at which counsel should be engaged. Trigger on "dispute advice", "claim escalation", "is this a claim", "notice of claim", "time extension request", "mediation or arbitration", "termination notice", or a pasted change order rejection, delay narrative, or RFI thread that has turned contested. Works with any standard form or bespoke contract. The user supplies the contract and its clauses; the skill reads what it is given and never recalls a notice period, a ladder step, or a procedure from memory. Procedural only: it produces an escalation memo and a notice letter draft, and it is not legal advice.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **dispute-advisor**.

In Claude Code:

```
/plugin install dispute-advisor --marketplace DavidCho1999/archaiflow-skills
```
