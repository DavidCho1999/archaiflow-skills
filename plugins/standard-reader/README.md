# Standard Reader

Read a referenced standard for what it covers and what it does not.

Reads any referenced standard — a test method, a product standard, a design standard, an industry guideline — and answers the four questions that decide whether it means anything on this project: what it actually covers, whether it binds here or is only advisory, which edition is the one that binds, and what it deliberately does not address. A standard cited in a specification is often doing none of the work anybody assumes. Trigger on "what does this standard say", "is ASTM E-something relevant here", "they referenced a standard", "does this standard apply to us", "standard-reader", or a standard cited in a spec, a submittal, or a manufacturer's claim. Carries no standard text: everything comes from the document you supply or the publisher, never from recall, since standards are revised and paraphrase drifts. It does not certify compliance and does not replace the code consultant or the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
