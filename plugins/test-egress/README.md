# Test Egress

Check one egress question - pass, fail, or marginal.

Single-question egress gut-check (occupant load, exit count, common path, travel distance) — user pastes or authorizes fetch of operative § text; PASS / FAIL / MARGINAL with explicit attribution. Carries no IBC values internally.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **test-egress**.

In Claude Code:

```
/plugin install test-egress --marketplace DavidCho1999/archaiflow-skills
```
