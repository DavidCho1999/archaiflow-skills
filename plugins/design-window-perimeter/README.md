# Design Window Perimeter

Detail a window head, jamb, and sill in the order they get installed.

Details the three sides of an opening as a sequence rather than as three sections: takes the wall assembly, the window type and how it is anchored, then works the head, the jamb and the sill in the order the trades actually build them, laps each control layer over the one below it, and names where water that gets past the window is collected and put back out. Trigger on "window head jamb sill", "window perimeter detail", "sill pan", "flashing sequence at an opening", "how does the air barrier close at a window", "punched opening detail", "design-window-perimeter", or a window and a wall build-up named with a request for how they meet. Supplies the sequencing and lap logic and the questions each side has to answer; supplies no dimension, no shim space, no sealant joint size, no code requirement and no proprietary product. Requires the wall assembly as input and does not design it. It does no structural work and does not replace the enclosure consultant or the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
