# Fit-Out Study

Fit a programme into a shell somebody else built.

Tests whether a tenancy works in a shell that is already there, which is a different problem from fitting a building on a site: the grid, the core, the servicing and the base building's own rules are fixed, and the programme has to bend around them. Establishes what is actually immovable before laying anything out, works the programme against the fixed points, and separates what the landlord provides from what the tenant does, since that boundary decides the budget and it is in a document nobody has read. Trigger on "fit out", "will this programme fit in this space", "tenant improvement", "test fit for a lease", "is this floor plate any good for us", "fit-out-study", or a floor plan of an existing building with a programme to place in it. Carries no areas, no ratios and no code requirements; areas come from the user and the lease's measurement basis from `area-measurement`. `test-fit` works a site under zoning limits; this works a shell under a lease. It does not replace the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
