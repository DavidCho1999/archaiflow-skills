# Draft ASI

Instruct the contractor without changing cost or time.

Draft an Architect's Supplemental Instruction (AIA G710-2017) for instructions with no change to Contract Sum or Contract Time. Use /draft-ccd for changes that DO affect cost/time; use /draft-bulletin for permit-set bulletin/addendum cover language.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-asi**.

In Claude Code:

```
/plugin install draft-asi --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/draft-asi
