# Parti Study

Find the one idea the scheme is actually organized by, and test it.

Works the organizing idea of a scheme rather than its appearance: states the parti in one sentence, tests whether the plan actually obeys it, finds the places it breaks and asks whether each break is a compromise or a second idea competing with the first, and checks the parti against the constraints it has to survive. Generates alternatives only as different organizing ideas from the same constraints, never as variations of one. Trigger on "parti", "what is the organizing idea here", "is this scheme actually about anything", "concept diagram", "the plan feels arbitrary", "parti-study", or a scheme handed over with a question about what holds it together. Carries no formal vocabulary and no house style; the idea is yours and the skill tests whether the drawing keeps it. It does not critique the design — `design-critic` and `independent-critic` do that, deliberately separately — and does not replace the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
