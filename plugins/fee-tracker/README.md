# Fee Tracker

Track earned fee against billed, invoice by invoice.

Tracks a project's design fee in docs/practice/fees.md: the contract fee by phase, percent complete as you state it, earned fee computed from the two, invoices as issued and as paid, and the aging of what is outstanding, with the arithmetic shown. Trigger on "fee tracker", "how much have we billed", "earned vs billed", "unbilled", "outstanding invoices", "receivables", "invoice log", "fee-tracker", or an invoice to record. Percent complete is your judgment and the skill never estimates it; fees, invoice amounts, and dates come from you, in your currency, and nothing is recalled or benchmarked. Estimating a fee before there is a contract is fee-estimator's job; this starts when the contract is signed. It is a project record, not accounting: no tax, no ledger, no payroll costs.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **fee-tracker**.

In Claude Code:

```
/plugin install fee-tracker --marketplace DavidCho1999/archaiflow-skills
```
