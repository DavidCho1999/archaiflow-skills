# Draft Email

Write the project email, and check whether it should be an email at all.

Drafts a project email and first decides what kind of thing it is: most are nothing, some create a record, and a few are doing the work of an instrument that has its own form and its own consequences. Screens the draft for the language that accepts scope, grants approval, or directs work without meaning to, and says plainly when the message should be an ASI, a change directive, an additional services request, or a formal letter instead. Carries no contract terms and no house style; the agreement and the office's own conventions come from you. For a letter to the building department use `/draft-letter`; for answering an RFI use `/draft-rfi-response`; for rewriting technical language for a client use the `client-translator` skill.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-email**.

In Claude Code:

```
/plugin install draft-email --marketplace DavidCho1999/archaiflow-skills
```
