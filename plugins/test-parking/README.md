# Test Parking

Check required parking count and accessible spaces.

Single-parcel parking gut-check (required count vs provided + accessible-space allocation per 2010 ADA §208) — user pastes or authorizes fetch of zoning + ADA text; PASS / FAIL / MARGINAL with explicit attribution. Carries no values internally.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **test-parking**.

In Claude Code:

```
/plugin install test-parking --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/test-parking
