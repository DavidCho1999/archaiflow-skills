# Test ADA

Math-check one accessibility clearance against the source.

Single-element 2010 ADA clearance gut-check — for each compliance topic the command WebFetches the operative § live from ada.gov (or accepts a paste) and math-checks provided dimensions against the verbatim source. Carries no ADA values internally. Federal 2010 ADA only — state amendments (CA Title 24 Pt 2 Ch.11B, ICC A117.1) are out-of-scope.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **test-ada**.

In Claude Code:

```
/plugin install test-ada --marketplace DavidCho1999/archaiflow-skills
```
