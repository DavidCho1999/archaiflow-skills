# Explain Load Path

Trace how load travels from roof to foundation.

Trace a structural load path (gravity → lateral → foundation) on a section, plan, or framing element per ASCE 7-22 / IBC 2024 Ch. 16

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-load-path**.

In Claude Code:

```
/plugin install explain-load-path --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/explain-load-path
