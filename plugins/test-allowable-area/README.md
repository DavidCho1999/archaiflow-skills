# Test Allowable Area

Check a building's allowable area.

Single-building allowable-area gut-check (Tabular base × frontage modifier × sprinkler factor) against IBC Ch. 5 — user pastes or authorizes fetch of operative IBC tables; PASS / FAIL / MARGINAL with explicit attribution. Carries no IBC values internally.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **test-allowable-area**.

In Claude Code:

```
/plugin install test-allowable-area --marketplace DavidCho1999/archaiflow-skills
```
