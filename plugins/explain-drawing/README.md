# Explain Drawing

Explain a detail, callout, or section in plain English.

Interpret an architectural drawing detail, callout, or section in plain English (NCS sheet citation, NA conventions)

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-drawing**.

In Claude Code:

```
/plugin install explain-drawing --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/explain-drawing
