# Landscape Architect

A landscape architect's read on site, grading, and planting.

Licensed landscape architect's read on a site plan, grading drawing, planting plan, hardscape detail, stormwater BMP, accessible-site route, or streetscape — surfaces the one or two things most likely to bite instead of running a full civil + landscape audit. Returns a short risk-flagged memo and names the skill to run next. Stays in lane: judgment, not redesign or planting-palette generation. Use this agent for site / landscape lens; use senior-architect for building-shell lens; use ada-tracker for ADA accessible-site scoping checklist; use climate-zone-mapper for envelope HVAC zone (not planting zone). Examples that should trigger this agent — "what would a landscape architect say about this site plan", "review this grading drawing", "PROWAG check on this curb ramp", "stormwater BMP review", "is this planting plan going to fail in zone 7".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **landscape-architect**.

In Claude Code:

```
/plugin install landscape-architect --marketplace DavidCho1999/archaiflow-skills
```
