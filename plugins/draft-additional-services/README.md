# Draft Additional Services

Draft an additional services request before the work is done, not after.

Drafts an additional services request and first tests whether it is one: checks the work against the agreement's own basic services definition and the proposal's exclusions, establishes what caused it and whether the cause was within the architect's control, and checks whether notice was required before the work began. Writes the request around the cause rather than around the hours, because a client refuses an hours-based request and accepts a cause-based one. Carries no rates and no contract terms; both come from the executed agreement. For the original proposal use `/draft-proposal`; for tracking the fee use the `fee-tracker` skill.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-additional-services**.

In Claude Code:

```
/plugin install draft-additional-services --marketplace DavidCho1999/archaiflow-skills
```
