# Explain U-value

Check an assembly's R-value against your climate zone.

Interpret an envelope assembly R-value or U-factor against IECC 2024 (or ASHRAE 90.1-2022) by climate zone — pass/fail with prescriptive vs performance path

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-u-value**.

In Claude Code:

```
/plugin install explain-u-value --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/explain-u-value
