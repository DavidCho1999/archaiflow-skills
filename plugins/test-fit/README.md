# Test Fit

Run the arithmetic on what fits a site under your limits.

Runs feasibility arithmetic for a site: floors times plate against your FAR and height limits, gross to net through your efficiency, net to units through your unit sizes, parking through your ratio, laid out as side-by-side scenarios with every step shown. Trigger on "test fit", "what fits", "does it pencil", "how many units", "buildable area", "yield study", "massing numbers", "test-fit", or a pasted site area with zoning limits. Every limit and assumption comes from you or your zoning summary, cited: the skill never supplies a FAR, an efficiency factor, a unit size, or a parking ratio from memory or from web search, and a scenario built on an unverified limit says so on its face. Arithmetic only, no geometry: setback envelopes, floor plates that actually fit the lot, and massing are drawing work it does not do. Early feasibility, not a zoning compliance check (test-far checks one scheme) and never a substitute for the zoning analysis.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **test-fit**.

In Claude Code:

```
/plugin install test-fit --marketplace DavidCho1999/archaiflow-skills
```
