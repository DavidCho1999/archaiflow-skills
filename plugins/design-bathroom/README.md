# Design Bathroom

Lay out a bathroom around the plumbing wall and the door swing.

Lays out a domestic bathroom or ensuite from the two things that actually constrain it — where the waste can run and which way the door swings — rather than from the fixtures. Works ventilation, the wet area and its waterproofing, storage, and the reach and clearance around each fixture, and separates what is fixed by the building from what is a choice. Trigger on "bathroom layout", "ensuite", "can we move the toilet", "powder room", "where does the shower drain go", "design-bathroom", or a bathroom to be laid out or moved. Carries no clearances, no fixture dimensions and no ventilation rates; each comes from the code you quote, the accessibility standard, or the fixture's own data. For an accessible restroom to a standard use `design-accessible-restroom`; for commercial fixture counts use `/count-plumbing-fixtures`. It does not replace the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
