# Senior Architect

A 25-year architect's gut-check on what will break the project.

25-year senior architect's gut-check on a design, drawing, RFP, or project decision — surfaces the 1–2 things most likely to actually break the project (cost / schedule / liability / client / AHJ) instead of running a multi-axis checklist. Returns a short risk-flagged memo with pattern-grounded reasoning, then points at the structured-review skill that should run next. Stays in lane: judgment, not redesign. NA AEC only. Use this agent for senior risk-flagged read with phase/AHJ context; use independent-critic for blind multi-axis design critique; use design-critic skill for in-thread iterative critique workflow. Examples that should trigger this agent — "what would a senior architect say about this", "principal-level read on this scheme", "is this design going to bite us", "gut check from a 25-year architect", "what's the one thing I'm missing here".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **senior-architect**.

In Claude Code:

```
/plugin install senior-architect --marketplace DavidCho1999/archaiflow-skills
```
