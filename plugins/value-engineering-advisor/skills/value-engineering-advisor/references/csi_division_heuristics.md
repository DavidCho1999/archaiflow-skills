# CSI Division-Keyed VE Heuristics

Common VE moves organized by CSI MasterFormat 2020 division, with default classification and the design / performance / lifecycle / risk impact heuristics that drive the call. Project context (phase, owner type, certification commitments, named AHJ) overrides generic heuristics.

These are heuristics — not blanket rules. Always apply the six-axis assessment from `ve_assessment_axes.md`.

---

## Division 03 — Concrete

| VE move | Default | Why |
|---------|---------|-----|
| Reduce concrete strength (e.g., 5000 psi → 4000 psi) | ❌ unless SE confirms | Structural calc must re-run; usually a small savings vs. SE re-design fee + rebar add. |
| Eliminate AESS (architecturally exposed structural concrete) finish | ❌ if visible | Identity loss in lobby / atrium / canopy. ✅ if BOH. |
| Substitute board-form for smooth form | ❌ if signature element | Concept-level move. |
| Reduce admixture spec (water reducer, accelerator) | ⚠️ | Confirm with SE / cold-weather concreting plan. |
| Eliminate integral color | ✅ if non-public | Owner often accepts. ❌ in public spaces. |

## Division 04 — Masonry

| VE move | Default | Why |
|---------|---------|-----|
| Brick → painted CMU (full elevation) | ❌ identity | Major envelope identity loss. |
| Custom brick blend → standard color | ⚠️ | Aesthetic depending on context. |
| Eliminate stone water table | ⚠️ | Detailing impact at base; check waterproofing. |
| Reduce mortar joint type (raked → struck) | ✅ usually | Cosmetic; minor labor savings. |

## Division 05 — Metals

| VE move | Default | Why |
|---------|---------|-----|
| Reduce galvanizing on exterior steel | ❌ in coastal / freeze-thaw | Corrosion lifecycle — Axis 3. ⚠️ inland temperate. |
| Eliminate AESS on exposed structure | ❌ if visible | Identity loss. |
| Substitute lighter steel sections requiring more pieces | ⚠️ | SE re-run; check connection detail count. |

## Division 06 — Wood, Plastics, Composites

| VE move | Default | Why |
|---------|---------|-----|
| Custom millwork → stock casework | ❌ in public, ✅ in BOH | Identity-driven. |
| Hardwood veneer → laminate | ⚠️ public, ✅ BOH | Visual class drop. |
| Eliminate in-wall blocking (grab bars, TV, art) | ❌ irreversible | Axis 6 — retrofit cost 5–10× install. |
| Reduce trim profiles (custom → stock) | ⚠️ | Detail-level concept impact. |

## Division 07 — Thermal & Moisture Protection

**The most consequential division for VE — most cuts are below-grade or behind-finish, and irreversibility + risk transfer dominate.**

| VE move | Default | Why |
|---------|---------|-----|
| Eliminate fluid-applied air barrier in favor of housewrap | ❌ | Energy model + blower-door target tied to fluid-applied; AHJ re-submittal. Axis 2 + Axis 5. |
| Reduce roof insulation R-value below code | ❌ | IECC compliance — non-negotiable. |
| Reduce roof membrane warranty (20 yr → 10 yr) | ⚠️ | Axis 3 lifecycle; require LCCA + owner sign-off. |
| Eliminate cover board on roof | ❌ | Manufacturer warranty void; fire / hail risk. |
| Eliminate redundant below-grade waterproofing | ❌ | Axis 5 risk transfer; failure cost 50–100× install. |
| Substitute lower-spec sealants (e.g., generic for spec'd silicone) | ⚠️ | Joint movement / warranty impact at envelope joints. |
| Reduce vapor retarder spec | ⚠️ | Climate-zone-dependent; confirm with envelope consultant. |

## Division 08 — Openings

| VE move | Default | Why |
|---------|---------|-----|
| Custom curtainwall → stock storefront in lower floors | ⚠️ | Aesthetic + thermal performance drop; Axis 1 + Axis 2. |
| Triple glazing → double glazing | ⚠️ | Energy model re-run; LL97 / Title 24 / PHIUS impact. |
| Eliminate impact-rated glazing in coastal | ❌ | Code (Florida Building Code, ASCE 7 wind-borne debris zones). |
| Reduce STC on demising / corridor doors | ❌ in residential, ⚠️ in office | IBC / occupancy-driven. |
| Substitute spec'd hardware brand (Sargent / Best / Schlage) for generic | ⚠️ | ADA / accessibility set must match A117.1 §404.2.7. |
| Eliminate door positioner / hold-open | ✅ usually | Owner can add later. |

## Division 09 — Finishes

**The "easy" division — most cuts are reversible, but identity / certification risks live here.**

| VE move | Default | Why |
|---------|---------|-----|
| Wood ceiling → ACT in public lobby | ❌ identity | Concept loss. |
| Wood ceiling → ACT in BOH corridor | ✅ | Neutral. |
| Marble → porcelain in restroom | ✅ usually | Performance equivalent. |
| Custom paint → standard color | ✅ | Reversible. |
| Reduce flooring spec (LVT thickness 5mm → 3mm) | ⚠️ | Lifecycle warranty (Axis 3). |
| Eliminate acoustic ceiling spec (NRC 0.85 → 0.55) | ❌ in open office, ✅ in private | Acoustic comfort + WELL. |
| Substitute spec'd carpet manufacturer | ✅ usually | Reversible; check LEED EQ Credit (low-emitting). |

## Division 10 — Specialties

| VE move | Default | Why |
|---------|---------|-----|
| Reduce signage spec (custom → standard) | ⚠️ | ADA §703 still applies. |
| Eliminate toilet partitions (custom finish → standard powder coat) | ✅ | Reversible. |
| Reduce visual display board count | ✅ if owner accepts | FF&E-adjacent. |

## Division 14 — Conveying Systems

| VE move | Default | Why |
|---------|---------|-----|
| Reduce elevator cab finish (custom → standard) | ✅ usually | Cosmetic. ❌ if signature lobby cab. |
| Reduce elevator capacity (3500 lb → 3000 lb) | ⚠️ | Verify against IBC §3002 + traffic study. |
| Eliminate destination-dispatch | ✅ if owner OK | Operational, reversible. |

## Division 21 — Fire Suppression

**Most cuts here trigger NFPA 13 re-design and AHJ re-review. Default ❌ unless trivial.**

| VE move | Default | Why |
|---------|---------|-----|
| Eliminate sprinklers (any portion) | ❌ | NFPA 13 / IBC; almost never approvable. |
| Reduce hazard classification (OH-2 → OH-1) | ❌ unless use changes | Density requirements re-set. |
| Quick-response heads → standard response | ⚠️ | Check IBC §903 / NFPA 13. |

## Division 22 — Plumbing

| VE move | Default | Why |
|---------|---------|-----|
| Reduce fixture quality (commercial → builder-grade) | ⚠️ | Lifecycle + WELL Water Concept impact. |
| Eliminate water filtration | ✅ if not WELL/spec'd | Reversible. |
| Reduce hot water recirculation pump spec | ⚠️ | Comfort + IECC if specified. |

## Division 23 — HVAC

| VE move | Default | Why |
|---------|---------|-----|
| VRF → conventional split / VAV | ⚠️ | Lifecycle (Axis 3); LL97 / electrification commitment risk. |
| Eliminate energy recovery ventilator (ERV) | ❌ if required by code | IECC C403.7 thresholds. ⚠️ otherwise. |
| Reduce HVAC zoning (1 zone per 5,000 sf vs. 2,500 sf) | ⚠️ | Comfort + ASHRAE 55. |
| Substitute commodity AHU for spec'd unit | ⚠️ | Acoustic, capacity, controls compatibility. |
| Eliminate humidity control | ❌ in healthcare/lab/museum, ✅ in office | Use-dependent. |

## Division 26 — Electrical

| VE move | Default | Why |
|---------|---------|-----|
| Reduce panel capacity / spare capacity | ⚠️ | Future flexibility (electrification, EV, PV). |
| Substitute spec'd light fixtures for generic | ⚠️ | LPD per IECC C405 + design intent in lit spaces. |
| Eliminate emergency / standby generator (if not code-required) | ⚠️ | Owner risk during outage; institutional often ❌. |
| Reduce conduit size / eliminate spare conduits | ❌ irreversible | Axis 6; future-proofing. |
| Substitute switchgear manufacturer | ⚠️ | Owner standardization, parts/service. |

## Division 27 — Communications & Division 28 — Electronic Safety/Security

| VE move | Default | Why |
|---------|---------|-----|
| Owner-furnished AV / data | ✅ usually | Common in commercial. |
| Reduce cable-tray spec | ⚠️ | Future flexibility. |
| Eliminate access control prep (conduit + back boxes) | ❌ irreversible | Axis 6. |

## Divisions 31–33 — Earthwork, Exterior Improvements, Utilities

| VE move | Default | Why |
|---------|---------|-----|
| Reduce planting count | ⚠️ | Entitlement / zoning landscape requirement; check approved site plan. |
| Substitute planting (canopy tree → ornamental) | ⚠️ | Heat-island + LEED SS credit. |
| Reduce paving spec (asphalt thickness, concrete strength) | ⚠️ | Lifecycle + freeze-thaw. |
| Eliminate stormwater management feature | ❌ | AHJ-approved drainage plan; permit re-review. |
| Reduce site lighting spec | ⚠️ | Safety + IES + light-trespass ordinance. |

## How to use this reference

1. Identify the VE item's CSI division.
2. Look up the heuristic above.
3. Apply the six-axis assessment in `ve_assessment_axes.md` — heuristics are starting defaults; project context (phase, owner type, certifications, AHJ) can move the classification.
4. Cite this file plus the relevant code section in the memo's "why" column.
