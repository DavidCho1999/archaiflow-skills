# Value Engineering

Sort a cost-cutting list into accept, alternate, and block.

Sorts a cost-cutting list against an issued design into accept, accept with an alternate, and block, with the reasoning written out per item across design intent, performance, lifecycle cost, schedule, risk transfer, and reversibility. Trigger on "VE review", "value engineering", "review this VE list", "where can we cut", "cost reduction options", "VE round 2", or a pasted contractor proposal with substitutions and savings figures. Works with any contract and any specification format. Performance requirements come from the user's own specification and contract; the skill supplies the sorting method and never a code threshold or a performance value from memory. Produces a recommendation memo, not a directive.

This is a skill. It runs in Chat, Cowork and Claude Code.
