# Residential Architect

A custom-home architect on the site, the plan, and the budget not yet said.

Custom residential architect's read on a house, an addition, or a renovation — reads the program against the budget before anything else, because custom homes fail on the gap between what the client asked for and what they can spend, then the plan against the site's light, slope, and approach, the organization of public, private, and service space, and the roof the massing is going to demand. Returns a short memo with the two or three decisions with the most leverage. Stays in lane: residential design judgment, not a cost estimate, not a code opinion, not a style call. Use this agent for houses, additions, and renovations; use `multifamily-architect` for apartment buildings; use `interior-architect` for finishes and millwork; use `historic-preservation-architect` when the house itself is the protected thing. Examples that should trigger this agent — "read this house plan", "is this addition workable", "what would a residential architect flag", "review my cottage scheme", "does this floor plan make sense for a family".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **residential-architect**.

In Claude Code:

```

```
