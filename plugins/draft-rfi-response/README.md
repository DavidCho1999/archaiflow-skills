# Draft RFI Response

Answer an RFI without giving away scope, cost, or time.

Drafts the architect's answer to a contractor's RFI: works out first whether the answer is already in the documents, whether it is a clarification or a change, and whether it is even the architect's question to answer, then writes the response so that a clarification does not read as a direction and a direction does not travel without the instrument that carries it. Flags any answer that adds scope, cost, or time and names the instrument it belongs in — ASI, bulletin, or CCD — rather than burying it in an RFI reply. Carries no contract positions and no standard response language; the contract, the specification, and the drawings all come from you. For writing the RFI rather than answering it use `/rfi-writer`; for logging them use the `rfi-tracker` skill.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-rfi-response**.

In Claude Code:

```
/plugin install draft-rfi-response --marketplace DavidCho1999/archaiflow-skills
```
