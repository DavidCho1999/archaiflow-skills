# Design Below-Grade Assembly

Build up a below-grade wall or slab where water comes first and drying does not.

Builds a below-grade wall or slab assembly from the water condition first: takes the groundwater regime, the soil, the structure, how the space below grade will be used and whether the waterproofing can ever be reached again, then places the water, thermal and vapor control layers in an order, gives every layer a job, and works the joints, penetrations and the at-grade transition where below-grade work actually fails. Trigger on "below grade waterproofing", "basement wall build-up", "foundation wall assembly", "slab on grade vapor barrier", "blindside waterproofing", "design-below-grade-assembly", or a foundation wall and a water table named with a request for what goes between them. Supplies the ordering logic and the questions each condition has to answer; supplies no thickness, no permeance, no hydrostatic head, no code requirement and no proprietary product. It does not size drainage, does not do geotechnical or structural work, and does not replace the waterproofing consultant or the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
