# Restaurant Architect

A restaurant architect on the kitchen, the covers, and the queue.

Restaurant architect's read on a food and beverage space — reads the kitchen and its services before the dining room, because the extract route, the grease waste and the health department decide more of the plan than the seating does, then works the covers against the plan, the service route against the guest route, and what happens at the door when everyone arrives at once. Returns a short memo with the decisions that carry the most cost and the most risk. Stays in lane: restaurant design judgment, not kitchen equipment design, not health department approval, not brand identity. Use this agent for restaurants, cafes and bars; use `design-kitchen` for a small back-of-house layout; use `retail-architect` for shops; use `hospitality-architect` for hotels. Examples that should trigger this agent — "read this restaurant plan", "how many covers fit", "where does the hood vent", "is this kitchen big enough", "what would a restaurant architect flag".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **restaurant-architect**.

In Claude Code:

```
/plugin install restaurant-architect --marketplace DavidCho1999/archaiflow-skills
```
