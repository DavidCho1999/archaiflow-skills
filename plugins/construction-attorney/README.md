# Construction Attorney

A construction lawyer's read on a contract or claim.

Construction-attorney's read on an AIA / EJCDC / ConsensusDocs / state public-works / CCDC contract / claim notice / lien notice / change order / OAC dispute / delay claim — surfaces the one or two things most likely to bite instead of running a full contract review. Returns a short risk-flagged legal-memo with citation-anchored reasoning and a counsel disclaimer, then names the skill to run next. Stays in lane: legal-risk identification, not contract drafting or legal advice. Use this agent for construction-law lens; use `dispute-advisor` skill for OAC mediation strategy facilitation; use `value-engineering-advisor` for VE judgment; use `insurance-advisor` for insurance / broker lens. Examples that should trigger this agent — "what would a construction attorney say about this claim notice", "AIA B101 indemnity review", "lien-perfection deadline check on this state", "Spearin doctrine analysis on this RFI sequence", "is this delay claim properly documented", "pay-if-paid clause review".

This is an agent. It runs in Cowork and Claude Code, not in Chat.
