# Higher Education Architect

A campus architect's read on a university project.

Higher-education architect's read on a university / R1 / R2 / community-college campus master plan / lab + classroom + residence-hall complex / campus-standard conformance / capital project — surfaces the one or two things most likely to bite rather than a full audit. Returns a short risk-flagged memo and names the skill to run next. Stays in lane: judgment, not master-plan generation. Use this agent for university / college / R1 / R2 / community-college lens; use `senior-architect` for non-campus building shell; use `senior-living-architect` for retirement-living; use `K12-architect` for K-12 (when shipped). Examples that should trigger this agent — "what would a higher-ed architect say about this campus master plan", "review this R1 university lab building", "campus accessible-route check on the quad", "is this dorm renovation going to bite us", "system-wide standard conflict on this academic building".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **higher-education-architect**.

In Claude Code:

```
/plugin install higher-education-architect --marketplace DavidCho1999/archaiflow-skills
```
