# Design Addition

Work out how new construction meets the building already there.

Works an addition or a renovation at the place it actually gets decided: the joint between new and existing. Settles the relationship the new work takes to the old, then works the six things that cross the joint — structure, envelope, services, levels, fire separation and finishes — and separately establishes what the work triggers in the existing building, since a change of use or a threshold crossed can require upgrades to parts of the building nobody was touching. Trigger on "addition", "extension", "renovation", "how does the new bit meet the old", "does this trigger an upgrade", "matching the existing", "design-addition", or new work proposed against a building that already exists. Carries no code thresholds and no structural values; existing-building provisions are jurisdictional text you quote and capacity is the engineer's. Read `existing-conditions-survey` first: an addition designed against unverified dimensions is designed twice. It does not replace the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
