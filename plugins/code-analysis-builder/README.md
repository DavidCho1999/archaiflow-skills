# Code Analysis

Assemble the code analysis block for a cover sheet.

Assembles the code analysis block that goes on a permit set cover sheet, in six parts: occupancy classification, construction type, height and area with the allowable-area arithmetic shown, fire-resistance summary, means-of-egress summary, and accessibility statement. Trigger on "code analysis", "cover sheet code block", "G001 code block", "code-analysis-builder", "allowable area calc", "construction type check", or a pasted program with use, footprint, and sprinkler condition. Works in any jurisdiction. The user names the governing code and edition and supplies every value by typing it, pasting the clause or table row, or naming a file to read. The skill never supplies a code value from memory or from web search, and any line without a supplied value is printed as unverified rather than filled in. Does not replace the Architect of Record or the AHJ.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **code-analysis-builder**.

In Claude Code:

```
/plugin install code-analysis-builder --marketplace DavidCho1999/archaiflow-skills
```
