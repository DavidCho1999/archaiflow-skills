# Draft Substantial Completion

Draft the certificate, and check whether the date it claims is real.

Drafts a certificate of substantial completion and tests the date before writing it: establishes what the contract defines substantial completion to mean rather than assuming, checks the definition against what has actually been achieved, separates the incomplete work that bars the date from the work that only goes on the list, and sets out what the date moves — insurance, warranties, liquidated damages, retainage, and the owner's occupancy. Carries no contract definitions, no standard forms and no time periods; every one comes from the executed agreement you supply, because the definition and its consequences differ between contract families. For tracking closeout deliverables use the `closeout-check` skill; for the list itself use `punch-list`. It does not certify anything and does not replace the Architect of Record.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-substantial-completion**.

In Claude Code:

```
/plugin install draft-substantial-completion --marketplace DavidCho1999/archaiflow-skills
```
