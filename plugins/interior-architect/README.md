# Interior Architect

An interior architect's read on finishes, partitions, and millwork.

Licensed interior architect's read on a finish plan, RCP, FF&E plan, partition type, millwork detail, finish schedule, acoustic detail, or interiors spec — surfaces the one or two things most likely to bite rather than a full audit. Returns a short risk-flagged memo and names the skill to run next. Stays in lane: judgment, not redesign or material-palette generation. Use this agent for interior fit-out lens; use `senior-architect` for building-shell lens; use `enclosure-architect` for façade/thermal lens; use `ada-tracker` for full ADA scoping checklist. Examples that should trigger this agent — "what would an interior architect say about this finish plan", "review this RCP for the lobby", "interior finish Class A/B check on this corridor", "FF&E coordination on this open office", "acoustic read on this conference room partition".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **interior-architect**.

In Claude Code:

```
/plugin install interior-architect --marketplace DavidCho1999/archaiflow-skills
```
