# Design Elevator

Hold space for the shaft, the pit, the overrun, and the machine.

Holds the architectural space an elevator installation needs from the consultant's or manufacturer's data: the hoistway, the pit below the lowest landing, the overrun above the highest, the machine and controller wherever the product puts them, and the lobby and door dimensions at every level. Works the constraints that decide the building — what the pit does to the foundation, what the overrun does to the roof or the height limit, and where the machine has to be if there is no machine room. Trigger on "elevator pit depth", "lift overrun", "machine room-less", "how big is the hoistway", "elevator shaft coordination", "design-elevator", or an elevator specification handed over to fit into a building. Carries no dimensions, no capacities, no speeds and no code requirements; every one comes from the manufacturer, the elevator consultant, or the code you quote. It does not do traffic analysis and does not replace the elevator consultant or the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
