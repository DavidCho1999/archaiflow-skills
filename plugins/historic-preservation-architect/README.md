# Historic Preservation Architect

A preservation architect's read on work to a historic building.

Licensed historic-preservation architect's read on a rehabilitation set, federal Historic Tax Credit (HTC) Part 1/2/3 application, SHPO/LPC review submission, window-replacement spec, masonry-restoration scope, addition to a historic resource, IEBC pathway selection, ADA-and-preservation reconciliation, or Section 106 review — surfaces the one or two things most likely to bite rather than a full audit. Returns a short risk-flagged memo and names the skill to run next. Stays in lane: judgment, not redesign or treatment-plan generation. Use this agent for historic-preservation lens; use senior-architect for general design lens; use enclosure-architect for envelope detail; use code-compliance-review for IBC. Examples that should trigger this agent — "SOI Standards check on this addition", "Part 2 application readiness for federal HTC", "is this window replacement going to fail SHPO review", "Preservation Brief 14 conformance check", "NYC LPC Certificate of Appropriateness scope question".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **historic-preservation-architect**.

In Claude Code:

```
/plugin install historic-preservation-architect --marketplace DavidCho1999/archaiflow-skills
```
