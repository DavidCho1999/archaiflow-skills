# Architect of Record

A licensed architect's read on what you are about to seal.

Licensed architect-of-record's read on a sealed drawing set, submittal review stamp, addendum, RFI response, delegated-design package, contract scope-of-services question, AHJ filing, or insurance/liability question — surfaces the one or two things most likely to bite rather than a full audit. Returns a short risk-flagged memo and names the skill to run next. Stays in lane: AOR liability / responsibility lens, not design quality. Use this agent for AOR liability / responsibility lens; use `senior-architect` for design-quality lens; use `senior-pm` for fee/scope (when shipped); use `dispute-advisor` for active claims. Examples that should trigger this agent — "what would the AOR say about signing this", "AOR liability check on this submittal review", "should the AOR stamp this addendum", "scope-of-services question on B101 §3.6", "is this an AOR responsibility or contractor's".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **architect-of-record**.

In Claude Code:

```
/plugin install architect-of-record --marketplace DavidCho1999/archaiflow-skills
```
