# Explain AIA

Read a contract clause from all three sides.

Interpret an AIA contract clause (A201/B101/C401/A101) in plain English with multi-POV (Owner/Architect/Contractor) read

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-aia**.

In Claude Code:

```
/plugin install explain-aia --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/explain-aia
