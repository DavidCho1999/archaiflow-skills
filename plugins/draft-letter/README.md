# Draft Letter

Write a letter to the building department.

Draft AHJ correspondence — response to plan-check comments, alternative-method request, code-interpretation request. NA AHJs only (NYC DOB, FDNY, LADBS, CA DSA, CA HCAI). Use the rfi-writer skill for contractor RFIs; use the code-compliance-review skill for full code audit.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-letter**.

In Claude Code:

```
/plugin install draft-letter --marketplace DavidCho1999/archaiflow-skills
```
