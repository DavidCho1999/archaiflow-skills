# Design Beam

Size a simply-supported beam in steel, wood, or concrete.

Sizes a single simply-supported beam in steel, wood, or reinforced concrete for a known span, tributary load, and deflection limit, showing every step of the arithmetic. Trigger on "size beam", "preliminary beam size", "pick a section", "glulam beam size", "concrete beam size", "beam deflection check", "design-beam", or a pasted span with loads. Works with any design standard. The user names the standard, the design method, and supplies the load combinations, material properties, section properties, resistance factors, and deflection limit, by typing them, pasting the table, or naming a file. The skill never supplies an engineering value from memory or from web search. Preliminary sizing only, for a fully braced simple span, and never a substitute for the Engineer of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
