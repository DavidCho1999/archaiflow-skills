# Design Acoustic Separation

Build a separation for sound, where the flanking path decides the result.

Works acoustic separation between two spaces as a whole rather than as a wall or floor rating: establishes what the source is and what the receiver needs, then traces every path sound can take between them, because the assembly's tested rating describes the direct path only and the built result is set by whatever flanks around it. Names the structural decisions that have to be made early and cannot be fixed later. Trigger on "acoustic separation", "STC between these units", "impact noise from above", "flanking", "why is this wall not working acoustically", "design-acoustic-separation", or two spaces with a noise problem between them. Carries no ratings, no laboratory values and no criteria; the target comes from the code, the brief or the acoustician, and every assembly value is a tested figure you cite. It is not acoustic engineering and does not replace the acoustician or the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
