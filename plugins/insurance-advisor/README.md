# Insurance Advisor

Recommend policy types, limits, and a wrap-up structure.

Assembles a project insurance program recommendation: which policy types the project needs, what each one covers, the wrap-up against traditional structure decision, and a checklist to take to a broker. Trigger on "insurance program", "what limits should we carry", "wrap-up insurance", "builder's risk", "professional liability limits", "insurance review", or a pasted project profile with a coverage question. Works in any market. Limits, required coverages, and certificate formats come from the user's contract and their broker; the skill supplies the structure of the decision and never a limit figure or a required coverage from memory. Produces a recommendation memo and a broker request checklist, and is not broker advice, a quote, or a binder.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **insurance-advisor**.

In Claude Code:

```
/plugin install insurance-advisor --marketplace DavidCho1999/archaiflow-skills
```
