# Design Critic

Get a structured critique of a design.

This skill should be used when the user shares an architectural project (concept text, plans, sections, renderings, references) and asks for critique, feedback, or a second opinion. Trigger on 'design critique', 'review this design', 'critique this', 'second opinion', or when context implies the user wants challenge over validation. Generates a structured critique markdown in `docs/reviews/` and appends to the project review index.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **design-critic**.

In Claude Code:

```
/plugin install design-critic --marketplace DavidCho1999/archaiflow-skills
```
