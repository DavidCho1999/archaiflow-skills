# Fee Estimator

Estimate a design fee four ways and split it by phase.

Estimates a design fee four ways in parallel, as a percentage of construction cost, by area, as hourly against a cap, and as a lump sum, then splits the result by phase and by consultant and adds a reimbursables budget. Trigger on "fee estimate", "what should I charge", "design fee", "percent of construction cost", "lump sum or hourly", "consultant fee split", or a pasted program with a fee question. Works in any market. Every rate, percentage, phase split, consultant share, and any procurement cap comes from the user's own past projects, their contract, or the rule they name; the skill supplies the four methods and the comparison and never a benchmark figure from memory, since the published fee surveys are paywalled and cannot be quoted.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **fee-estimator**.

In Claude Code:

```
/plugin install fee-estimator --marketplace DavidCho1999/archaiflow-skills
```
