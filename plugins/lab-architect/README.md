# Lab Architect

A lab architect on the module, the services, and what the science needs.

Laboratory architect's read on a research or teaching lab scheme — starts from the planning module and the services strategy because those decide the building, checks whether the plate can carry the mechanical load a lab demands, reads containment and separation against the science actually proposed, and surfaces where flexibility has been claimed without being paid for. Returns a short memo with the decisions that carry the most cost and the most risk. Stays in lane: laboratory design judgment, not mechanical engineering, not biosafety certification, not a redesign. Use this agent for research, teaching and clinical labs; use `senior-mep-engineer` for the systems themselves; use `healthcare-architect` for clinical settings; use `higher-education-architect` for teaching buildings generally. Examples that should trigger this agent — "read this lab scheme", "is this module right", "can this plate take a lab", "lab planning review", "what would a lab architect flag here".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **lab-architect**.

In Claude Code:

```
/plugin install lab-architect --marketplace DavidCho1999/archaiflow-skills
```
