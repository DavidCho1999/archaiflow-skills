# Submittal Review

Review a shop drawing or product data against the documents.

This skill should be used during construction administration when the user shares a contractor submittal — shop drawings, product data, samples, or mockup documentation — and wants it reviewed for conformance with the contract documents. Trigger on 'review this submittal', 'shop drawing review', 'check this product data', 'submittal log', 'is this approved', 'spec compliance check', 'AIA G712', or pasted submittal content paired with CA-phase context. Generates a structured submittal-review markdown in `docs/submittals/` and appends to the project submittal log.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **submittal-review**.

In Claude Code:

```
/plugin install submittal-review --marketplace DavidCho1999/archaiflow-skills
```
