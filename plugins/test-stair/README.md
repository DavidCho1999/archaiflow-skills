# Test Stair

Check stair geometry when you already have the code text.

Single-shot stair geometry math against IBC §1011 + 2010 ADA §504/§505 source text the user has already in hand. Lighter than the `design-stair` skill — `/test-stair` is for "I have the § text and the dims, just math it" while `design-stair` walks the full multi-turn fetch + comparison workflow. Carries no IBC / ADA values internally. Federal IBC + Federal 2010 ADA only.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **test-stair**.

In Claude Code:

```
/plugin install test-stair --marketplace DavidCho1999/archaiflow-skills
```
