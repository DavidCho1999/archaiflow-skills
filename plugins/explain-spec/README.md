# Explain Spec

Explain a specification section in plain English.

Interpret a CSI MasterFormat specification section in plain English (Part 1/2/3 breakdown, NA conventions)

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-spec**.

In Claude Code:

```
/plugin install explain-spec --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/explain-spec
