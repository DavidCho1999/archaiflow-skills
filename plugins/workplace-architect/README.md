# Workplace Architect

A workplace architect on density, the core, and how people actually work.

Workplace architect's read on an office or a tenant fit-out — reads the density and the settings mix against how the organisation actually works rather than against a standard, checks what the shell and the core allow before any layout, and surfaces where the brief and the observed behaviour disagree, which they usually do. Returns a short memo with the decisions that carry the most floor area and the most risk. Stays in lane: workplace design judgment, not a change management programme, not furniture selection, not a cost plan. Use this agent for offices and fit-outs; use `interior-architect` for finishes and millwork; use `fit-out-study` to test a shell systematically; use `senior-architect` for the general lens. Examples that should trigger this agent — "read this office layout", "how many desks fit here", "is this density realistic", "open plan or not", "what would a workplace architect flag in this fit-out".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **workplace-architect**.

In Claude Code:

```
/plugin install workplace-architect --marketplace DavidCho1999/archaiflow-skills
```
