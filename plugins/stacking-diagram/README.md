# Stacking Diagram

Stack the programme against what the floor plate and the core will actually take.

Distributes a programme vertically against the constraints that actually decide it: the floor plate you have, the core capacity, the loads and heights each use demands, and the ground-level frontage everything competes for. Places the uses that cannot move first, then works down the list, and reports every floor where the programme assigned exceeds what the plate can hold. Trigger on "stacking diagram", "stack the programme", "which floor does this go on", "vertical zoning", "how many floors do we need", "stacking-diagram", or a programme and a floor plate handed over with a request for how it distributes. Carries no areas, no floor-to-floor dimensions, no lift capacities and no loading figures; every one comes from you or from `space-program`, `design-core` and `test-fit`. It does not size the core, does not lay out a floor and does not replace the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
