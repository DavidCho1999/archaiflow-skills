# Stakeholder Map

Map who decides what, and who talks to whom.

This skill should be used when the user wants to map the stakeholders, decision rights, and communication structure of an AEC project. Trigger on 'stakeholder map', 'who decides what', 'project stakeholder analysis', 'RACI matrix for this project', 'map the stakeholders', 'governance plan', or pasted project context where governance, sign-off authority, or communication cadence is the question. Generates a structured stakeholder map markdown in `docs/stakeholders/` and appends to the project stakeholder index.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **stakeholder-map**.

In Claude Code:

```
/plugin install stakeholder-map --marketplace DavidCho1999/archaiflow-skills
```
