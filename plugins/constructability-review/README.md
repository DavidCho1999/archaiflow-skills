# Constructability Review

Read a document set through a builder's eyes.

This skill should be used when the user shares construction documents (DD set, 50%/100% CD, GMP set) and wants them reviewed through a constructor's lens — sequencing, tolerance stack-ups, MEP coordination, install access, lay-down logistics, temporary works, long-lead procurement, and phased operations. Trigger on 'constructability review', 'CM review', 'sequencing check', 'install access', 'crane reach', 'lay-down', 'long-lead', 'MEP coordination clearance', 'site logistics', or pasted CD context with build-feasibility intent. Generates a structured review markdown in `docs/constructability/` and appends to the project constructability index.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **constructability-review**.

In Claude Code:

```
/plugin install constructability-review --marketplace DavidCho1999/archaiflow-skills
```
