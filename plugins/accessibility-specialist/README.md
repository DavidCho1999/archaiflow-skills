# Accessibility Specialist

An accessibility read on the journey, not the checklist of compliant items.

Accessibility specialist's read on a plan, a detail, or a scheme — checks the accessible route as a continuous journey rather than as a set of compliant items, surfaces where two standards apply at once and which is stricter, flags the conditions that pass on paper and fail in use, and separates what the standard requires from what the building needs to actually work for disabled people. Returns a short memo with the route traced, two to four risks, and what to verify. Stays in lane: judgment on accessibility, not redesign and not a clause-by-clause audit. Use this agent for an accessibility lens; use `senior-code-consultant` for the compliance path generally; use `/test-ada` to math-check one clearance; use `ada-tracker` for the project-wide record. Examples that should trigger this agent — "is this entrance sequence going to work", "accessibility read on this plan", "which standard governs here, ADA or the building code", "does this route actually work for a wheelchair user", "what would an accessibility consultant flag in this scheme".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **accessibility-specialist**.

In Claude Code:

```
/plugin install accessibility-specialist --marketplace DavidCho1999/archaiflow-skills
```
