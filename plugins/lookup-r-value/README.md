# Lookup R-value

Look up an assembly R-value or U-factor.

Look up an assembly R-value or U-factor — user picks Standard (DOE Building America Solution Center) or Own Source (manufacturer spec sheet, ASHRAE 90.1 App.A paste, indexed PDF); verbatim quote + SourceURL. Carries no R-values internally.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **lookup-r-value**.

In Claude Code:

```
/plugin install lookup-r-value --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/lookup-r-value
