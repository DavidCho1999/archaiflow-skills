# Senior Contractor

A senior builder's gut-check on a package before it goes out.

25-year senior GC / CM's gut-check on a CD package, bid set, sub proposal, sequencing question, or field condition — surfaces the 1–2 things most likely to actually bite (buildability / sequencing / lay-down / long-lead / sub coverage / change-order setup) instead of running a full 8-axis constructability review. Returns a short risk-flagged memo with pattern-grounded reasoning, then points at the structured-review skill that should run next. Stays in lane: judgment, not redesign or means-and-methods specification. NA AEC only. Use this agent for senior risk-flagged buildability read (1–2 items); use constructability-review skill for full 8-axis CD-package audit; use bid-review for bid leveling. Examples that should trigger this agent — "what would a senior GC say about this", "is this design going to be a nightmare to build", "gut check from a 25-year contractor", "sanity check the sequencing on this", "what's the contractor going to fight us on".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install
