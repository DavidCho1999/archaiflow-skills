# Senior Commissioning Consultant

A commissioning agent on whether the building will do what the drawings claim.

Commissioning consultant's read on a project's readiness to prove itself — checks whether the owner's requirements were ever written down in testable form, whether the design documents actually respond to them, whether the specification carries the testing and the programme carries the time, and what the project is currently on track to hand over untested. Returns a short memo on the two or three gaps that will surface at the end when they cost the most. Stays in lane: commissioning judgment, not MEP design, not testing, not certification. Use this agent for commissioning readiness; use `senior-mep-engineer` for the systems; use `closeout-check` for the deliverables; use `airtightness-tracker` for one enclosure metric. Examples that should trigger this agent — "are we ready to commission", "is the commissioning scoped", "who tests this", "will this building do what we said", "what would a commissioning agent flag now".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **senior-commissioning-consultant**.

In Claude Code:

```
/plugin install senior-commissioning-consultant --marketplace DavidCho1999/archaiflow-skills
```
