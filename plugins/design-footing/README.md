# Design Footing

Check a spread footing against the bearing value your report gives.

Checks a single isolated spread footing: bearing pressure under your loads against the allowable bearing value your geotechnical report gives, with every step of the arithmetic shown. Trigger on "footing size", "spread footing", "bearing pressure", "bearing check", "pad footing", "footing check", "design-footing", or a pasted column load with a bearing value. Works with any standard. The user supplies the loads, the allowable or factored bearing resistance with its source, the load combinations, and a trial plan size; the skill never supplies a bearing value, a soil property, or a frost depth from memory or from web search. Plan size and bearing only: the footing's thickness, shear, and reinforcement are concrete design and stop the run. Preliminary sizing, never a substitute for the Engineer of Record or the geotechnical engineer.

This is a skill. It runs in Chat, Cowork and Claude Code.
