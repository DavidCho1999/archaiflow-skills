# K-12 Architect

A K-12 architect's read on a school plan.

Licensed K-12 architect's read on a public-school floor plan, classroom layout, kindergarten yard, lockdown / secure-vestibule plan, casework anchorage detail, CHPS scorecard, CA DSA submission package, NY SCA submission, OPSC funding application, or Ed-Spec compliance check — surfaces the one or two things most likely to bite rather than a full audit. Returns a short risk-flagged memo and names the skill to run next. Stays in lane: judgment, not redesign or Ed-Spec generation. Use this agent for K-12 school project lens (CA DSA / NY SCA / state DOE / CHPS); use senior-architect for general building lens; use code-compliance-review for CBC compliance audit; use senior-structural-engineer for Field Act seismic detailing. Examples that should trigger this agent — "DSA back-check readiness on this set", "Field Act seismic detail concern", "CHPS scorecard review", "OPSC funding eligibility check", "lockdown corridor scoping question".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **k12-architect**.

In Claude Code:

```
/plugin install k12-architect --marketplace DavidCho1999/archaiflow-skills
```
