# Explain Vapor Retarder

Explain what a vapor retarder does, and what it is being asked to do here.

Explains vapor control in plain English for a specific assembly rather than in general: what diffusion is and how it differs from air leakage, what the retarder classes mean as a system, which face of the insulation a retarder is being asked to sit on in the assembly you describe, and what that position does to the direction the assembly can dry. Carries no permeance figures and no code requirements — which class your climate zone permits is code text you quote, and which class a product falls into is on its data sheet. For the arithmetic use the `condensation-check` skill; for air leakage rather than diffusion use `air-barrier-trace`; for laying out a new build-up use `design-wall-assembly`.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-vapor-retarder**.

In Claude Code:

```
/plugin install explain-vapor-retarder --marketplace DavidCho1999/archaiflow-skills
```
