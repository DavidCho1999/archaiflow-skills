# Retail Architect

A retail architect on the frontage, the flow, and the landlord's rules.

Retail architect's read on a store, a storefront, or a tenant unit — reads the frontage and how the store is entered before anything inside, works the flow against what the operator actually sells and how they replenish it, and surfaces the landlord's criteria and the base building constraints that will overrule half the design. Returns a short memo with the decisions that carry the most sales area and the most risk. Stays in lane: retail design judgment, not merchandising, not a fit-out cost plan, not brand identity. Use this agent for shops, storefronts and retail tenancies; use `restaurant-architect` for food and beverage; use `fit-out-study` to test a unit systematically; use `interior-architect` for finishes. Examples that should trigger this agent — "read this store layout", "is this storefront going to work", "what will the landlord say about this shopfront", "where does the back of house go", "what would a retail architect flag".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **retail-architect**.

In Claude Code:

```
/plugin install retail-architect --marketplace DavidCho1999/archaiflow-skills
```
