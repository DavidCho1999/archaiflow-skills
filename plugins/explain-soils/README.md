# Explain Soils

Explain a geotechnical recommendation in plain English.

Interpret a geotechnical recommendation (bearing capacity, lateral pressure, frost depth, site class) in plain English with ASCE 7-22 / IBC 2024 Ch. 18 citation

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-soils**.

In Claude Code:

```
/plugin install explain-soils --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/explain-soils
