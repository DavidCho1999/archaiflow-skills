# Canon Provenance

Bundled canon (`canon.md`) is curated from publicly known projects. Each entry was verified 2026-05-09 against publicly available project records (architect websites, ArchDaily, Dezeen, published monographs).

Per the skill's anti-pattern list (`SKILL.md` → "Inventing projects. If unsure of existence, year, or architect, omit the entry."), it is preferable to ship fewer verified entries than more potentially-fabricated ones.

## 2026-05-09 audit — entries removed

The following entries were present in `canon.md` prior to 2026-05-09 and removed:

1. **"Olafur Eliasson studio extension at Castel di Sangro"** (Museums → Subterranean / hillside).
   - Reason: **Fabricated.** Olafur Eliasson is an artist (Studio Olafur Eliasson is an art studio in Berlin), not an architect with a building credit at Castel di Sangro. No such project exists in the public record.

2. **"Solo House (one of several) — see specific architect"** (Housing → Single-family canon).
   - Reason: **Placeholder, not a precedent.** The Solo Houses are a developer-curated series (Cristian Bourdais) with multiple architects (Pezo von Ellrichshausen, OFFICE Kersten Geers David Van Severen, etc.). A canon entry must point to a specific built project by a specific architect; "see specific architect" is a note-to-self, not a citation.

3. **"House on the Cliff — see specific"** (Coastal / waterfront).
   - Reason: **Placeholder, not a precedent.** Generic name with no architect, year, or location. Multiple unrelated projects share the name (Fran Silvestre's "House on the Cliff" in Calpe, etc.); without specifying which, this is not a usable canon entry.

4. **"Tofino Beach Houses — various Canadian west-coast references"** (Coastal / waterfront).
   - Reason: **Placeholder, not a precedent.** "Various references" is a search prompt, not a citable project. Tofino has multiple notable houses (e.g., Patkau Architects' work) but the canon must list specific named projects with architect + year + location.

5. **"Kvarteret 39 Strandparken — Berg Arkitektkontor, Sundbyberg"** (Mass timber / sustainable).
   - Reason: **Wrong attribution.** Strandparken (the cross-laminated timber residential blocks in Sundbyberg, Stockholm) is by Wingårdh Arkitektkontor (with C.F. Møller on later phases), not Berg Arkitektkontor. Rather than risk leaving a guess in place, the entry was removed; if a verified version is needed, re-add as `Strandparken — Wingårdh Arkitektkontor, 2013, Sundbyberg, Sweden` after confirming the specific phase against Wingårdh's project page.

6. **"Therme Vals — also coastal-adjacent geometry"** (duplicate listing in Coastal / waterfront).
   - Reason: **Wrong category and duplicate.** Vals is an alpine village in Graubünden, ~200 km from any coast; "coastal-adjacent geometry" is incorrect. The legitimate Therme Vals listing is preserved under its own Spa / wellness section (extracted from the original Museums section because Therme Vals is a thermal spa, not a museum).

## How to add a new entry

Before adding to `canon.md`, confirm all four of:

1. **Project name** as published.
2. **Architect / lead designer** at completion (note collaborators if attribution is shared).
3. **Year of completion** (not topping-out, not commission, not award year).
4. **Location** (city + state/country at minimum).

If any one cannot be confirmed against a primary source, do not add the entry. A short canon is a strong canon.
