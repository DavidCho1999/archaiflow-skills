# Create Site Visit Report

Write a field observation report with photos.

Create an architect's site visit / field observation report (Word + photos, AIA B101 §3.6.2)

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **create-site-visit-report**.

In Claude Code:

```
/plugin install create-site-visit-report --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/create-site-visit-report
