# Draft Proposal

Draft a fee proposal that says what is not included.

Drafts a fee proposal built around its exclusions and its assumptions rather than around its scope, because every dispute about an architect's fee is a dispute about something the proposal did not say. Establishes the basis before the number: what phases, what deliverables, how many revisions, how long the programme is assumed to be, which consultants are included, and what triggers additional services. Then writes it so that the client can see what they are not buying. Carries no rates, no percentages and no phase splits; the fee comes from you or from `fee-estimator`. For an additional services request use `/draft-additional-services`; for reviewing an owner's agreement use the `contract-review` skill.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-proposal**.

In Claude Code:

```
/plugin install draft-proposal --marketplace DavidCho1999/archaiflow-skills
```
