# Code Editions by NA Jurisdiction (as of 2026 Q2)

Which IBC / state-code edition is in force in major North American jurisdictions, plus the typical accessibility, energy, and fire codes that overlay. Use to anchor the "code basis" step in code review.

This is a moving target — every state and major city updates on its own cycle. Confirm with the AHJ for the actual project.

---

## Federal (U.S.)

- ADA 2010 Standards (DOJ + ATBCB) — applies nationwide for Title II/III obligations.
- ABA (Architectural Barriers Act) — federal-government-funded projects use ABA Standards (similar to ADA 2010 with federal-specific overlays).
- USACE projects: UFGS sections + IBC 2021 baseline + UFC.
- GSA projects: P-100 + IBC 2021 baseline + agency overlays.
- VA medical facilities: VA design guides + FGI Guidelines + NFPA 99 / 101.

## Canada — by province

Canadian projects use the National Building Code of Canada (NBC) as a model code, adopted with provincial amendments. The current NBC is **NBC 2020** (published 2022, adopted on rolling provincial schedules through 2024-2026).

| Province | Code | Notes |
|---|---|---|
| Ontario | OBC 2024 (NBC 2020 + ON amends) | Effective 2024-01-01 |
| British Columbia | BCBC 2024 (NBC 2020 + BC amends) | Effective 2024-03-08; BC Energy Step Code overlay |
| Alberta | ABC 2023 (NBC 2020 + AB amends) | Effective 2024-03-01 |
| Quebec | QCC Ch. I.1 (NBC 2015 + QC amends) | Updates rolling; CCQ has separate construction safety code |
| Manitoba | MBC 2020 (NBC 2020 + MB amends) | Adopted 2023 |
| Saskatchewan | SBC 2020 (NBC 2020 + SK amends) | Adopted 2024 |

National Energy Code of Canada for Buildings (NECB) 2020 is the typical energy reference; provincial energy codes may exceed.

## Other reference codes commonly applicable

- **NFPA 101 Life Safety Code 2021** — required for Joint Commission / CMS healthcare; AHJ may use instead of (or with) IBC for life safety.
- **NFPA 13 / 13R / 13D** (sprinklers), 14 (standpipes), 72 (alarm), 110 (emergency power) — referenced from IBC.
- **ICC A117.1-2017** — accessible/usable buildings, referenced by IBC Ch. 11.
- **IECC 2021** — baseline energy; many jurisdictions use it directly or via ASHRAE 90.1-2019/2022.
- **ASHRAE 90.1-2019** — alternate energy compliance path.
- **FGI Guidelines 2022** — required by many state DOH for hospitals / outpatient.
- **NFPA 99 2024** — healthcare facilities.
- **California Title 24** — California-specific, supersedes IECC.
- **IECC + Stretch Code** — MA, OR, NYC LL97 — additional overlay for energy.
