# Code Compliance Review

Audit a plan across eight egress and accessibility axes.

Audits a floor plan, schematic set, or program layout across eight egress and accessibility axes: use and occupant load, egress capacity and exit count, common path of travel, travel distance, exit access and door width, exit separation, accessibility, and fire-resistance assemblies. Trigger on "code review", "egress check", "life safety review", "plan check", "check egress", "accessibility check", "exit count", "travel distance", or a pasted plan with a code question. Works in any jurisdiction. The user names the governing code and edition and supplies each limit by typing it, pasting the clause, or naming a file to read. The skill never supplies a limit from memory or from web search. Writes a dated review file and appends to a project index, with every unverified axis counted on the face of the review. Does not replace the Architect of Record or the AHJ.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In Claude Code:

