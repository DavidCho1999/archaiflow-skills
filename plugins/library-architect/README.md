# Library Architect

A library architect on a building type that changed under everyone.

Library architect's read on a public or institutional library — starts from what this library is actually for now, since the type has changed from storing books to hosting people and most briefs still describe the old one, then works the collection against the floor loading and the plan, the noise gradient from loud to quiet that has replaced the single silent room, and the staffing reality that decides how much of the building can be open at once. Returns a short memo with the decisions that carry the most area and the most operational cost. Stays in lane: library design judgment, not collection management, not a service plan, not a cost plan. Use this agent for libraries and learning commons; use `higher-education-architect` for campus buildings generally; use `civic-architect` for other municipal work. Examples that should trigger this agent — "read this library plan", "how much shelving fits", "where does the quiet space go", "can one person staff this floor", "what would a library architect flag".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **library-architect**.

In Claude Code:

```
/plugin install library-architect --marketplace DavidCho1999/archaiflow-skills
```
