# Test Ramp

Check a ramp's slope, landings, and handrails.

Single-ramp gut-check (slope / cross-slope / rise per run / landing / handrail / edge protection) against 2010 ADA §405 and IBC §1012 — user pastes or authorizes fetch of operative § text; PASS / FAIL / MARGINAL with explicit attribution. Carries no values internally.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **test-ramp**.

In Claude Code:

```
/plugin install test-ramp --marketplace DavidCho1999/archaiflow-skills
```
