# Draft Payment Application

Draft a contractor payment application.

Draft a contractor payment application (AIA G702 cover + G703 continuation, Excel default)

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-payment-application**.

In Claude Code:

```
/plugin install draft-payment-application --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/draft-payment-application
