# Generate Weekly Report

Generate a weekly project status report.

Generate a weekly project status report (Markdown internal / PDF owner-facing, NA conventions)

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **generate-weekly-report**.

In Claude Code:

```
/plugin install generate-weekly-report --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/generate-weekly-report
