# Drawing Checklist

Get a drawing-set checklist for the phase you are in.

This skill should be used when the user needs a phase-specific drawing-set checklist for an architectural project — SD, DD, CD, or IFC. Trigger on 'make a checklist', 'drawing set review', 'CD checklist', 'DD set review', or pasted phase + project-type context. Generates a structured checklist markdown in `docs/checklists/` and updates the project checklist index.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **drawing-checklist**.

In Claude Code:

```
/plugin install drawing-checklist --marketplace DavidCho1999/archaiflow-skills
```
