# Phase Deliverables

Reference for per-phase deliverable expectations. Phase percent-complete ranges below are common practice (typically aligned with AIA B101-2017 §3.2 / §3.3 / §3.4 / §3.5 phase descriptions, but the percent values themselves are office-convention not AIA-mandated). Sheet enumerations and level-of-detail lists are common-practice synthesis, not direct quotations of any published authority. Project contracts may override these — defer to contract language when present.

See `_provenance.md` for source authorities and verification status. Items marked `[verify B101-2017 §X.X]` need the exact section pin confirmed.

---

## SD — Schematic Design (~15-30% complete)

**Source:** Phase scope per AIA B101-2017 §3.2 (Schematic Design Phase Services). Percent-complete range (15-30%) is office convention — no AIA / NCS pin available. Typical-sheet list is common practice; verify against firm standards.

**Intent:** Establish the project concept, scale, massing, and key program relationships. Confirm zoning, code path, and site response.

**Typical sheets:**

- G-001 cover sheet (project name, address, team, sheet index)
- G-002 code summary (occupancy, construction type, allowable area, exiting strategy at concept level)
- A-001 site plan (massing footprint, setbacks, north arrow, property line)
- A-100 series floor plans (single-line walls, room names, no dimensions or schedules)
- A-200 series exterior elevations (massing, fenestration intent, material zones)
- A-300 series building sections (1-2 key sections, floor-to-floor heights)
- Optional: 3D massing views, key precedent references, concept narrative

**Level of detail:**

- Single-line walls
- Room names without numbers
- No door/window schedules, no wall types, no details
- Material intent only (no specs)
- Structural and MEP coordination is conceptual — note major moves only

**Owner deliverable:** narrative + drawings sufficient to confirm program, scale, and budget order-of-magnitude. _Source: AIA B101-2017 §3.2 generally describes SD-phase deliverables [verify B101-2017 §3.2.5 for explicit deliverable list]._

## DD — Design Development (~35-50% complete)

**Source:** Phase scope per AIA B101-2017 §3.3 (Design Development Phase Services). Percent-complete range (35-50%) is office convention — no AIA / NCS pin available. Typical-sheet list is common practice; sheet-series naming follows NCS v6 Module 2.

**Intent:** Resolve the project to the point where systems, materials, and dimensions are fixed. Outstanding items should be selection-level, not strategy-level.

**Typical sheets:**

- G-series: cover, sheet index, code summary, life safety plans (egress, occupancy load, travel distance)
- A-100 plans with double-line walls, dimensions to grid and major openings, room numbers
- A-200 RCPs with ceiling heights, lighting layout intent, soffits, bulkheads
- A-300 elevations with fenestration sized, material zones called out, key heights
- A-400 building sections with floor-to-floor, structural depth zones, ceiling plenum
- A-500 wall sections at typical conditions (exterior, foundation-to-roof)
- A-600 enlarged plans (stairs, restrooms, kitchens, vertical transportation)
- A-700 schedules — door, window, partition (preliminary)
- A-800 details — typical assemblies (no full detail set yet)

**Level of detail:**

- Double-line walls, partition types tagged
- Dimensions to grid, openings, and key features
- Door/window/finish schedules in preliminary form
- Wall types defined; details for typical conditions only
- Structural grid coordinated with architectural plans
- MEP chases, shafts, and major equipment locations coordinated

**Owner deliverable:** drawings + outline specs sufficient for cost estimate within ~10%. _Source: AIA B101-2017 §3.3 describes DD-phase scope [verify B101-2017 §3.3.2 / §3.3.3 for outline-spec language]; cost-estimate accuracy is office convention._

## CD — Construction Documents (100% biddable)

**Source:** Phase scope per AIA B101-2017 §3.4 (Construction Documents Phase Services). "100% biddable" is office convention; AIA does not assign a numeric percentage. Sheet enumerations follow NCS v6 Module 2 sheet-series naming.

**Intent:** Drawings + specs are complete enough for a contractor to bid and build without interpreting design intent.

**Typical sheets:**

- All DD sheet series, fully resolved
- Complete schedules: door, window, partition, finish, hardware, equipment
- Full detail set: typical and project-specific assemblies, all transitions, all penetrations
- Wall sections at every distinct condition
- Enlarged plans for every special area
- Exterior wall details cover every joint, transition, termination
- Interior elevations for every wet area, casework, and significant feature wall
- Roof plan with drainage, penetrations, equipment, parapet conditions
- Reflected ceiling plans coordinated with MEP

**Level of detail:**

- Every dimension required to build is shown
- Every callout (detail bubble, section cut, elevation tag) lands on a real referenced sheet
- Every schedule entry references a real type
- All wall types, partition types, door types, window types defined
- Specifications cross-reference correctly
- Structural and MEP fully coordinated — clash check resolved

**Owner deliverable:** biddable / permit-ready set. Specs issued. No "by others" or "TBD" without contractual reason. _Source: AIA B101-2017 §3.4 describes CD-phase scope [verify B101-2017 §3.4.1 / §3.4.2]; "permit-ready" qualifier and the "no TBD / by others" rule are office convention._

## IFC — Issued for Construction (100% issued)

**Source:** "Issued for Construction" is industry/office convention for the post-permit set delivered to the contractor for construction. AIA B101-2017 does not define an "IFC" phase by name; bidding/negotiation is §3.5 and construction phase services are §3.6. The IFC issue itself is administrative, not a B101 service phase. Revision/delta conventions follow NCS v6 Module 2 + AIA G-series administrative documents.

**Intent:** The set the contractor is building from. CD set + final addenda + bulletin revisions incorporated.

**Typical sheets:**

- All CD sheets at final revision
- Revision cloud + delta tag for every change since the prior issue
- Title block updated to "Issued for Construction" with date
- Sheet index updated to current revision

**Level of detail:**

- Same as CD, with every revision incorporated
- No outstanding RFIs that block construction
- No "VIF" (verify in field) callouts unless intentional and noted

**Owner deliverable:** the set bound into the construction contract. Any change after this is via RFI, ASI, or change order. _Source: post-issuance change mechanisms (RFI / ASI / change order) follow AIA A201-2017 General Conditions and AIA G-series forms (G701 Change Order, G710 Architect's Supplemental Instructions, G714 Construction Change Directive). [verify A201-2017 §7 for change-order machinery]._
