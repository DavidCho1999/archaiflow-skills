# CSI MasterFormat 2020 — Division & Major-Section Index

**Source:** CSI MasterFormat 2020 Edition (Construction Specifications Institute).
**Last verified:** 2026-05-09.
**Authoritative reference:** csiresources.org/standards/masterformat. The CSI publication is the single source of truth for division and section titles. When CSI and this file disagree, CSI wins.

Top-level Division titles and a curated set of level-2 section titles under each. Use for completeness checking in spec review.

**Scope.** MasterFormat divisions (level-1, two-digit) are stable across editions and reliable. The level-2 section titles below are the ones that show up on most NA building projects — included as completeness-check hints, not as a substitute for CSI's full schema (1,500+ sections). Sub-sections at level-3 / level-4 (e.g., 08 41 13.16) drift edition-to-edition and are not enumerated here; verify those against the current CSI publication before turning a finding on them.

## Use this for completeness check

In Axis 1 of spec review, scan the spec book TOC against this index for the Divisions / sections the project requires. Missing Divisions or sections in scope but absent from the spec are findings.

This is the "what should be in a complete spec book" reference. For "is the section content complete," see the section-internal completeness axis (Axis 7).
