# Spec Review

Audit a spec book for gaps and drawing coordination.

This skill should be used when the user shares a project specification — full spec book, individual CSI MasterFormat sections, or specs paired with drawings — and wants it audited for division completeness, drawing-spec coordination, prescriptive vs performance balance, basis-of-design products, reference-standard currency, AHJ amendments, section-internal completeness, and OPR alignment. Trigger on 'spec review', 'spec audit', 'CSI review', 'check this spec section', 'are the specs and drawings coordinated', 'reference standards', 'basis of design', 'or equal language', or pasted spec content with completeness intent. Generates a structured review markdown in `docs/spec-reviews/` and appends to the project spec-review index.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **spec-review**.

In Claude Code:

```
/plugin install spec-review --marketplace DavidCho1999/archaiflow-skills
```
