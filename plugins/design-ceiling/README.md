# Design Ceiling

Set the ceiling height by what has to fit above it.

Works the ceiling as the place every discipline's leftovers land: adds up what has to fit in the plenum in the order it gets installed, finds the one crossing that sets the height for the whole floor, and works access, transitions and the elements that arrive late and wreck a reflected ceiling plan. Reports the height available against the height wanted. Trigger on "ceiling height", "what fits in the plenum", "reflected ceiling plan", "will the duct clear the beam", "ceiling access", "design-ceiling", or a floor-to-floor with a question about what it leaves. Carries no depths, no clearances and no code requirements; structural depths come from the engineer, service sizes from the MEP set, and required heights from the code you quote. It does not size services or structure and does not replace the engineers or the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
