# Structural Drawing Review

Read a structural set against the architectural, from the architect's side.

Reads a structural set the way an architect has to: not to check the engineering, but to find where the structure and the architecture disagree, where the frame lands in a space that has to stay clear, where a member's depth eats a ceiling, where the drawings defer something to a delegated design nobody has scoped, and where the structural set assumes an architectural layout that has since changed. Reports every conflict with both values and rules on neither. Trigger on "review the structural drawings", "does the structure work with the plan", "beam depth coordination", "is this deferred to a delegated design", "structural-drawing-review", or a structural set issued for coordination. Carries no loads, no spans and no code requirements; it does not check or second-guess the engineering. The counterpart for MEP is `mep-review`. It does not replace the structural engineer or the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
