# Draft General Note

Write a general note that says something, and put it on the right sheet.

Drafts a general note for a drawing sheet and first tests whether it should exist: checks whether the requirement already lives in the specification, whether it contradicts anything already on the sheet or in the set, whether it directs means and methods, and whether it belongs on this sheet or on the cover. Writes the note in the imperative, scoped to what it actually applies to, and flags any note that shifts responsibility to the contractor for something the documents should have shown. Carries no standard note libraries and no code text; every requirement in a note comes from you, the specification, or a clause you quote. For the text inside a drawing callout use `/draft-callout`; for a spec paragraph use `/draft-spec-snippet`; for auditing the whole set's conventions use `drawing-standards-audit`.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **draft-general-note**.

In Claude Code:

```
/plugin install draft-general-note --marketplace DavidCho1999/archaiflow-skills
```
