# Test Glazing

Check a window against the energy table for your zone.

Single-window prescriptive glazing gut-check (U-factor / SHGC / VT / window-to-wall ratio) against IECC Table C402.4 by climate zone — user pastes or authorizes fetch of operative IECC table; PASS / FAIL / MARGINAL with explicit attribution. Carries no IECC values internally.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **test-glazing**.

In Claude Code:

```
/plugin install test-glazing --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/test-glazing
