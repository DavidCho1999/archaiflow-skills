# Senior Elevator Consultant

A vertical transportation consultant on whether the cars and the shafts work.

Vertical transportation consultant's read on a scheme — says whether the number, capacity and speed of cars suits the population and the plate before the shafts are drawn, reads the lobby arrangement for how it will actually queue, and flags the pit, overrun and machine constraints that reach outside the shaft into the foundation, the roof and the height limit. Returns a short memo on the decisions that are expensive to reverse. Stays in lane: vertical transportation judgment, not a traffic analysis, not a product selection, not code compliance. Use this agent for lift strategy and shaft constraints; use the `design-elevator` skill to hold the space systematically; use `design-core` for the core's share of the plate; use `senior-code-consultant` for the compliance path. Examples that should trigger this agent — "how many lifts do we need", "will this lobby queue", "is the pit going to be a problem", "machine room-less or not", "what would an elevator consultant say about this core".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **senior-elevator-consultant**.

In Claude Code:

```
/plugin install senior-elevator-consultant --marketplace DavidCho1999/archaiflow-skills
```
