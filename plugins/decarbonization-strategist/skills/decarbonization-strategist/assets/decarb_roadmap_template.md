## Risk Flags

- **Regulatory landscape changes fast.** This roadmap reflects mandates as of [date]. Re-verify quarterly for IRA, LL97, BERDO, BEPS, Title 24, SB 253. References: `_provenance.md` re-verification triggers.
- **Cost benchmarks are heuristic.** Current cost data from RSMeans / RMI / NREL ATB; project-specific quotes required for capex commitment.
- **Energy model + LCA prove out the plan.** This roadmap is strategic; energy modeling consultant + LCA consultant produce the technical deliverables that satisfy permit + benchmarking + certification.
- **Resilience overlay required.** Electrified buildings have new vulnerabilities (grid outage = no heat). Name the backup strategy for critical loads here.

## Disclaimers

This roadmap is **strategic guidance**, not a technical deliverable. It does **not**:

- Replace whole-building energy modeling (use sustainability consultant + energy modeler).
- Replace LCA / embodied-carbon quantification (use LCA consultant).
- Replace MEP system sizing (use MEP engineer).
- Replace IRA + state + utility incentive applications (use sustainability consultant + tax counsel).
- Guarantee mandate compliance — actual compliance is proven by the energy model, LCA, final permit, and benchmarking submission.
- Quote IRA / mandate dollar values authoritatively — primary sources govern; this document cites them.

The phasing logic (Year 0 / 1–3 / 4–7 / 8–15) is internal to this skill — synthesized from RMI, ULI, A2030, and AIA. Adjust pacing to match the actual binding mandate deadline.
