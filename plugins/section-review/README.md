# Section Review

Read a section for what it resolves and what it draws around.

Reads any section — a sketch section, a building section, a wall section, a consultant's, an inherited one — for the thing a section exists to settle: whether the vertical dimensions actually add up, and what has been drawn around rather than resolved. A section is the only drawing where the structure, the services, the ceiling, the floor build-up and the envelope have to agree in the same line, which is why it is the drawing most often cut where the conflicts are not. Trigger on "read this section", "does this section work", "they sent a wall section", "check this section", "section-review", or any section handed over. Carries no dimensions or depths; anything measured is read off the drawing at its stated scale. `plan-review` reads a plan and `assembly-review` reads a stack; this reads the drawing where the vertical dimensions meet. It does not replace the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
