# Urban Designer

An urban designer's read on a master plan or public realm.

Urban designer's read on a master plan, form-based code (FBC) regulating plan, public-realm sketch, transect / frontage type, block-and-street pattern, parcelization study, mixed-use podium massing, or transit-oriented overlay — surfaces the one or two things most likely to bite instead of running a full master-plan review. Returns a short risk-flagged memo and names the skill to run next. Stays in lane: judgment, not redesign or block-pattern generation. Use this agent for master-plan / public-realm / form-based-code lens; use `senior-architect` for individual-building lens; use `landscape-architect` for site-grading / planting / stormwater lens; use `zoning-summary` for parcel-level zoning code lookup. Examples that should trigger this agent — "what would an urban designer say about this master plan", "review this form-based code regulating plan", "transect alignment check on this overlay", "is this block-and-street pattern walkable", "public-realm read on this TOD".

This is an agent. It runs in Cowork and Claude Code, not in Chat.

## Install

In Claude Code:

