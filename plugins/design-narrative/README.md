# Design Narrative

Write what the project is, for a reader who was not in the room.

Writes the project description that gets asked for again and again in different lengths and for different readers: a planning submission, a design review board, an award entry, a website page, a client's own report. Establishes who is reading and what they can do about it before writing a word, since a board that can refuse and a magazine that cannot are different documents, then builds one account of the project that the shorter versions are cut from rather than rewritten. Trigger on "design narrative", "project description", "write up the project", "we need a paragraph for the submission", "award entry text", "design-narrative", or a request for words about a building. Carries no house voice and no claims of its own; every fact comes from the project and every claim has to be true of the drawings. It does not replace the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
