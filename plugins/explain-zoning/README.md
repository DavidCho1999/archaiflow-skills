# Explain Zoning

Put a zoning clause in plain English for your site.

Interpret a zoning clause for a specific North American project site (plain English, with §-citation)

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-zoning**.

In Claude Code:

```
/plugin install explain-zoning --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/explain-zoning
