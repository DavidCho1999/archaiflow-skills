# Lookup Cost

Look up a cost-per-square-foot benchmark, quoted with its source.

Look up a $/sf cost benchmark for a building type or scope — user picks Standard (GSA P-100, Turner / Mortenson / RLB indices, federal benchmarks) or Own Source (RSMeans paste, GC quote, in-house cost database, indexed PDF); verbatim quote + SourceURL. Carries no $/sf values internally.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **lookup-cost**.

In Claude Code:

```
/plugin install lookup-cost --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/lookup-cost
