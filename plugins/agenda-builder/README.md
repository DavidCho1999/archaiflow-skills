# Agenda Builder

Build the agenda around what has to be decided, not what to talk about.

Builds an agenda for any project meeting from the decisions it has to produce rather than from the topics somebody wants to raise. Establishes who has to be there for each decision and whether they are coming, what has to be sent in advance for a decision to be possible, and what is being discussed with nobody present who can decide it — which is how a meeting produces a follow-up meeting. Trigger on "agenda for tomorrow", "what should we cover in this meeting", "build the agenda", "prep for the client meeting", "agenda-builder", or a meeting coming up with nothing prepared. Carries no meeting formats and no standard agendas; the items come from what this project actually needs settled. `meeting-notes-cleaner` handles what comes out of the meeting; this handles what goes in. It does not replace the principal or the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **agenda-builder**.

In Claude Code:

```
/plugin install agenda-builder --marketplace DavidCho1999/archaiflow-skills
```
