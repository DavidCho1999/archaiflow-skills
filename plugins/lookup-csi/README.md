# Lookup CSI

Find the spec section number for a product or scope.

Look up a CSI MasterFormat 2020 section number for a product, scope, or work category — user picks Standard (CSI public preview / publisher's Numbers and Titles list) or Own Source (project spec book, company spec library, indexed MasterFormat PDF); verbatim quote + SourceURL. Carries no MasterFormat values internally.

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **lookup-csi**.

In Claude Code:

```
/plugin install lookup-csi --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/lookup-csi
