# Client Translator

Turn technical language into client-ready wording, and back.

This skill should be used when the user has architecture/engineering technical text needing client-friendly rephrasing, OR a vague client wish needing translation into actionable technical options. Trigger on 'translate this for the client', 'put this in plain language', 'client-facing version', or pasted technical specs alongside client communication context. Generates a paired client-facing or technical document in `docs/client-comms/`.

This is a skill. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **client-translator**.

In Claude Code:

```
/plugin install client-translator --marketplace DavidCho1999/archaiflow-skills
```
