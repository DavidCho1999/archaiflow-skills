# Explain Code

Put a code section in plain English.

Interpret an IBC/IECC/NFPA/ADA section in plain English with §-level citation and jurisdictional amendment flags

This is a command. It runs in Chat, Cowork and Claude Code.

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **explain-code**.

In Claude Code:

```
/plugin install explain-code --marketplace DavidCho1999/archaiflow-skills
```

Full page: https://archaiflow.com/templates/commands/explain-code
