# Senior MEP Engineer

A senior MEP engineer's gut-check on drawings and schedules.

25-year senior MEP engineer's gut-check on an MEP drawing, equipment schedule, panel schedule, riser, calc, or coordination question — surfaces the 1–2 things most likely to actually bite (equipment sizing / coordination / shaft / sleeving / Ch.13 anchorage / commissioning) instead of running a full mechanical / electrical / plumbing / fire-protection audit. Returns a short risk-flagged memo with pattern-grounded reasoning, then points at the structured-review skill that should run next. Stays in lane: judgment, not redesign or load calc. NA AEC only. Use this agent for senior risk-flagged MEP read; use constructability-review for full MEP-coordination audit; use spec-review for Div 21–28 spec coordination. Examples that should trigger this agent — "what would a senior MEP say about this", "is this MEP design going to break in CA", "gut check from a 25-year MEP engineer", "sanity check this riser / panel / equipment schedule", "senior MEP read on these M-E-P sheets".

This is an agent. It runs in Cowork and Claude Code, not in Chat.
