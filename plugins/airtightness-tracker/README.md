# Airtightness Tracker

Track one airtightness target from the spec through the site to the test.

Keeps one dated record of a project's airtightness target from the moment it is written into the specification to the moment it is tested: what the target is and where it came from, which surface the enclosure boundary follows, every junction that has to be sealed and who owns it, every intermediate test and what it found, and every change that moves the number or the boundary. Trigger on "airtightness tracker", "blower door target", "track the air leakage requirement", "who owns this junction", "air barrier sign-off log", "airtightness-tracker", or an air leakage target named with a request to keep track of it. Carries no target values, no test standards and no unit conversions; the target, its units and its test method all come from the specification or the certification the project is chasing. It is not a test, does not model leakage, and does not replace the enclosure consultant or the Architect of Record.

This is a skill. It runs in Chat, Cowork and Claude Code.
