# Architectural Precedent Canon

A curated list of well-documented projects to draw from. Used as the default pool before reaching to memory. Not exhaustive — extend with project-specific picks.

When citing a project, also include the source link in the precedent file. Default sources: ArchDaily (archdaily.com), Dezeen (dezeen.com), the architect's own site.

> **Verification note (2026-05-09):** Each entry below is verified against publicly known project records as of 2026-05-09. To add a new entry: name, architect, year, and location must each be verifiable to a primary source (architect's website, ArchDaily/Dezeen with date, or published monograph). Per skill anti-pattern: if any of those four cannot be verified, omit the entry. See `_provenance.md` for the deletion log from the 2026-05-09 audit.

## Museums & galleries

- **Chichu Art Museum** — Tadao Ando, 2004, Naoshima, Japan. ~27,700 sf. Mass embedded into the island; roof is the site.

## How to use this canon

1. Identify the dominant axis of the user's brief (program / atmosphere / scale / site).
2. Pull 5-8 candidates from the matching sections above.
3. Check the user's brief for axes the canon doesn't cover — augment with non-canon picks but mark them as outside-canon.
4. For each picked precedent, assert three design *strategies* and the matched axis.
5. Add the source URL to the output file (leave the URL field blank to be filled with a quick web search if uncertain).

If a project on the user's brief doesn't have a strong canon match, surface that honestly: "Closest canonical match is X but it diverges on Y. Suggested expansion search: [terms]."
