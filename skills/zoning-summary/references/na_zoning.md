# North American Zoning Fundamentals

North American zoning is municipal — every US city/county and every Canadian municipality writes its own ordinance or by-law. There is no national zoning code in either country. This reference covers the universal categories and definitions; concrete numbers (FAR caps, setback feet/metres, parking ratios) come from the local ordinance / by-law and zoning map. Always look up the actual values for the parcel.

---

## 1. Zoning district designation

A parcel sits in one base district, often plus one or more overlays. Common base-district letter codes (vary by city):

| Family | Typical codes | Notes |
|--------|---------------|-------|
| Residential | R-1, R-2, R-5, RM, RH (Toronto: RD, RS, RM, RA) | Number/letter often correlates to allowed density / lot size |
| Commercial | C-1, C-2, CB, CN (Toronto: CL, CR) | Neighborhood vs. central business |
| Mixed-use | MU, MX, CMX, CR | Increasingly common; explicit form-based rules |
| Industrial | M-1, M-2, I, IL, IH (Toronto: E) | Light vs. heavy |
| Special | OS, P, PUD, OR | Open space, public, planned unit development |

The base-district name is meaningless without the local ordinance — `R-5` in Portland is not `R-5` in NYC, and `CR 2.5` in Toronto is unique to Toronto. Always cite the city + district code together.

## 2. Use groups — zoning vs. building code

Two parallel systems:

- **Zoning use group** (per city ordinance / by-law): controls *whether* a use is permitted, conditional, or prohibited on the parcel.
- **Building-code occupancy classification** (IBC Chapter 3 in the US, NBC Part 3 / OBC Part 3 in Canada): controls *how* the building must be built for that use (egress, fire, occupancy load).

Common IBC Use Groups for cross-reference (US):

- A — Assembly (theaters, restaurants, places of worship)
- B — Business (offices, banks, professional services)
- E — Educational
- F — Factory / industrial
- H — Hazardous
- I — Institutional (hospitals, jails, day care)
- M — Mercantile (retail)
- R — Residential (R-1 hotels, R-2 multi-family, R-3 1-2 family, R-4 assisted)
- S — Storage
- U — Utility / miscellaneous

NBC / OBC major occupancy classifications (Canada):

- A — Assembly (A1 performing arts, A2 general assembly, A3 arena, A4 open-air)
- B — Detention / care / treatment (B1 detention, B2 care/treatment, B3 care)
- C — Residential
- D — Business and personal services
- E — Mercantile
- F — Industrial (F1 high, F2 medium, F3 low hazard)

A site's zoning use group and building-code occupancy are independent. A use can be IBC `B` / NBC `D` and zoning `C-2` / `CR` simultaneously.

In the zoning ordinance / by-law, look up:
- **Permitted by right / as-of-right** — allowed without discretionary review.
- **Conditional / special exception / minor variance** — allowed only with public hearing, board approval, or conditional use permit.
- **Prohibited** — variance / re-zoning required (rarely granted).

## 3. Bulk regulations — what to look up

| Term | Definition | Notes |
|------|-----------|-------|
| FAR / FSI / Density | Gross floor area / lot area | US: FAR. Canada: FSI (Floor Space Index) or "Density". Some cities exclude basements, mechanical, balconies — read the definition |
| Lot coverage | Footprint / lot area (%) | Surface parking sometimes counted |
| Height limit | Feet / metres / stories | Some cities use both (lower of) |
| Front setback / front yard | Building line to front lot line | Often follows neighborhood pattern |
| Side setback / side yard | To side lot lines (each side) | May be sum + minimum |
| Rear setback / rear yard | To rear lot line | Often deeper than side |
| Min lot size / width / frontage | Minimums for new lots | Triggers subdivision review if not met |
| Open space / landscape / soft landscape ratio | Required pervious or planted area | Stormwater code may add |
| Angular plane / angular by-law (Canada) | Skyplane from rear or side lot line | Toronto, Vancouver, Montréal use these |

Bulk requirements often vary by use within the same district (residential vs. commercial in a mixed-use zone).

## 4. Common overlay districts

Overlays add restrictions on top of base zoning:

- **Historic district / Heritage Conservation District (Canada)** — design review required for exterior changes; demolition limits. SHPO (US) or Parks Canada / provincial heritage registry (Canada).
- **Floodplain / flood hazard** — FEMA-mapped (US) or provincial conservation authority maps (e.g. TRCA in Toronto). First-floor elevation, fill restrictions.
- **Transit overlay (TOD) / Major Transit Station Area (Ontario)** — reduced parking, height bonuses near transit.
- **Coastal / shoreland / waterfront** — buffer setbacks, impervious limits.
- **Airport approach / height overlay** — FAA Part 77 surfaces (US), NAV CANADA / Transport Canada limits (Canada).
- **Wellhead / aquifer / source water protection** — use restrictions.
- **Inclusionary zoning** — affordability set-aside on residential projects above a threshold (NYC, Toronto, Vancouver, etc.).
- **Design overlay / form-based code / urban design guidelines** — facade, materials, fenestration rules.

---

## 5. Parking requirements

- Minimum spaces per use type (per dwelling unit, per 1,000 SF or 100 m², per seat, per employee).
- Loading berth requirements for commercial / industrial.
- Bicycle parking minimums (increasingly common; standard in most Canadian cities).
- Maximums in TOD / downtown districts (caps to discourage driving).
- Accessible parking minimums (US: IBC Ch. 11 / ANSI A117.1. Canada: NBC / provincial barrier-free chapter, e.g. OBC 3.8).

Many cities (Minneapolis, Buffalo, Seattle, Toronto, Edmonton) have eliminated or reduced minimums in core areas — verify current text, not training data.

## 6. Special review triggers

A project may trigger discretionary review when it crosses thresholds — find these in the ordinance / by-law:

- Design review board / urban design panel (for new construction in defined districts or above a size threshold).
- Planning commission / zoning board / Committee of Adjustment (Ontario) approval for conditional uses or variances / minor variances.
- Environmental review:
  - US — state-level: CEQA (CA), SEQRA (NY); federal NEPA if federal nexus.
  - Canada — provincial Environmental Assessment Acts; federal IAA if federal nexus.
- Heritage / historic preservation commission (in historic / heritage districts).
- Site plan review / Site Plan Control approval (above a building size or use intensity).
- Subdivision approval / Plan of Subdivision (Ontario) for any lot creation.
- Stormwater / land disturbance permit (above an area threshold).
- Toronto: Section 37 / Community Benefits Charge (CBC) on density bonus.

Identifying triggers early protects the schedule.

---

## 7. Where to look

- **City / county zoning portal** — interactive zoning map + parcel lookup.
- **Local zoning ordinance / municipal code / zoning by-law** (US: Municode, American Legal, eCode360. Canada: city website + by-law PDFs).
- **Property assessor / GIS** — parcel boundary, lot area, frontage.
- **FEMA Flood Map Service Center** (US) / provincial conservation authority (Canada) — floodplain.
- **State Historic Preservation Office (SHPO)** (US) / provincial heritage registry + city heritage register (Canada) — historic listings.
- **Zoning verification letter / zoning compliance letter** from the city — for due diligence.

---

## 8. Easy-to-miss items

- Frontage requirement (vs. just lot width) — controls street-facing length.
- Stepback / upper-floor setback in form-based codes.
- Daylight plane / sky exposure plane (NYC, SF) and angular planes (Toronto, Vancouver, Montréal) — controls upper-floor mass.
- Floor plate maximum (some downtown codes; common in Toronto for tall buildings).
- Ground-floor active use requirement.
- Bird-friendly glazing requirements (NYC, Toronto, others).
- Right-of-way dedication / street widening / road allowance triggered by frontage.
- Shadow study requirement on adjacent open space (Toronto, Boston, others).
