# Broker RFP Checklist — Project Insurance Program

What to send to the licensed insurance broker for market quote on a project insurance program. The broker delivers the actual program; this checklist organizes the inputs.

---

## 1. Project Profile

- Project name + number.
- Project address + jurisdiction (named AHJ).
- Construction value (current estimate) + tier (Small / Mid / Large / Mega).
- Project type (commercial / multifamily / institutional / healthcare / industrial / heavy civil / mixed).
- Construction start + Substantial Completion + Final Completion (target dates).
- Phasing if applicable.

---

## 2. Delivery Method

- DBB / DB / CMAR / IPD / P3.
- Owner type (institutional / commercial / public / federal / non-profit / developer).
- GC / CMAR / DB-er identity (if procured) + insurance broker (if known).
- Sub-tier mix (small-many vs. large-few; sub list if available).

---

## 3. Site / Risk Profile

- Existing structure on site (Y/N) + condition.
- Phase I ESA result (clean / RECs identified / brownfield / known contamination).
- Coastal / wind / wildfire / seismic / flood exposure.
- Adjacent occupied buildings / live operations.
- Site security / lay-down area.
- High-exposure scope (demolition, abatement, deep excavation, structural steel erection, hot work, hazmat handling).

---

## 4. Coverage Requested

For each policy listed in the recommendation memo:

- Policy type.
- Carried by (owner / GC / sub / architect / EOR).
- Recommended limits (per the recommendation memo).
- Required endorsements (Additional Insured forms, Waiver of Subrogation, Primary & Non-Contributory, Per-Project Aggregate).
- Required notice of cancellation period.

---

## 5. Wrap-Up Feasibility Study (if applicable)

If the recommendation includes OCIP / CCIP, request:

- Feasibility study covering: estimated premium savings vs. administrative cost, sub-credit methodology, state regulatory compliance.
- TPA recommendation (in-house, third-party, broker-administered).
- Closeout tail period and premium estimate.
- Wrap-vs.-traditional cost comparison.

---

## 6. Builder's Risk Specifics

- Replacement value of the structure under construction (full).
- Soft costs to be covered (re-design fees, financing carrying costs, lost rent during reconstruction).
- Delay-in-Opening / Business Interruption (commercial / hospitality).
- Site-specific perils (Flood / Earthquake / Wind).
- Equipment Breakdown coverage.
- Resultant damage coverage.
- Covers FF&E? OFCI? OFOI?
- Coverage end date (Substantial Completion vs. Final Completion vs. occupancy).

---

## 7. Bonds

- Bond requirement (Y/N for each: Bid, Performance, Payment).
- Required bond amount (% of bid for Bid Bond; 100% of contract typical for P+P).
- Required surety rating + Treasury listing (Circular 570).
- Form (default AIA A310-2010 / A312-2010 unless owner specifies).

---

## 8. Architect / Engineer / CMAR PL Confirmation

For each design-team firm:

- Firm name + license / registration.
- PL carrier + limit + claims-made retroactive date.
- Tail / extended reporting period commitment (5–10 yr typical).
- Project-specific endorsement (if owner requires).

---

## 9. State-Specific Compliance Items

Owner / counsel + broker confirm state-specific items including:

- State Workers' Comp Board registration.
- State contractor licensing (CSLB, etc.).
- State OCIP / CCIP rules (CA Insurance Code §11751.82, NY WC Board, etc.).
- State coastal wind / flood requirements.
- Federal project flow-downs (FAR 52.228 series).
- Davis-Bacon prevailing-wage flow-down (federal-funded).

---

## 10. Contract References (for Broker Confirmation)

- Executed AIA A201-2017 + Exhibit A (or A201-2007, or alternate form like EJCDC C-700, ConsensusDOCS 200, federal SF-1442).
- Executed B101-2017 (architect's PL fill-ins).
- Owner's required Additional Insured language.
- Owner's required Waiver of Subrogation scope.

---

## 11. Schedule of Deliverables Requested from Broker

| Deliverable | Required by |
|-------------|-------------|
| Market quote with actual premiums | [Date] |
| Wrap-up feasibility study (if applicable) | [Date] |
| Sample certificate of insurance (ACORD 25) | [Date] |
| Sample evidence of property insurance (ACORD 27/28) | [Date] |
| Surety pre-qualification (if bonds required) | [Date] |
| Endorsement form list (CG 2010, CG 2037, etc.) | [Date] |
| Closeout tail estimate | [Date] |

---

## 12. Authorization

- Owner / Owner's Rep authorizes broker to approach the market on the above basis.
- Owner / Owner's Rep retains right to review and accept / reject quoted program.
- Broker compensation structure (commission / fee / hybrid) confirmed.
