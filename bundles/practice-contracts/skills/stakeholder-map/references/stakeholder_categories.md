# North American AEC Stakeholder Taxonomy

Reference list of stakeholder categories typical for US/Canadian AEC projects, with project-type variations and jurisdiction-specific authorities. Use to make sure no group is missed when building a stakeholder map.

---

## 1. Owner-side

| Stakeholder | Typical role | Notes |
|---|---|---|
| Owner (legal entity) | Contracting party | Name the LLC / corp / agency, not just "the owner" |
| Owner's rep / OPM | Day-to-day client interface | Often a separate firm (e.g., JLL, Cumming, CBRE, Hines for private; OPM firms for public) |
| Project manager (internal) | Owner-side PM | Distinct from owner's rep when both exist |
| End users | The people who will work / live / learn / be treated in the building | Usually multiple groups; each may have a champion |
| Finance | CFO, treasurer, budget office | Sign-off on budget changes, change orders above threshold |
| Board / trustees / council | Governance gate | Public bodies usually have monthly or quarterly meetings; private boards quarterly |
| Legal | Contract review, risk allocation | Engaged at contract execution and major change orders |
| IT / network | Technology infrastructure decisions | Critical for offices, healthcare, education, labs |
| Security (operations) | Physical + cyber security | Distinct from security consultant on design team |
| Facilities operations | Day-2 building operations | Should be involved in DD for FF&E, system selection, controls strategy |
| HR (if office) | Workplace strategy | Often drives unstated objectives ("retention", "return-to-office") |
| Risk / insurance | Insurer requirements (FM Global, Verisk for some industrials) | Drives some envelope, sprinkler, and resilience choices |

## 2. Design team

The discipline list scales with project type. Always include the first five; add the rest as project requires.

### Core (every project)

| Discipline | Role |
|---|---|
| Architect of Record (AOR) | Lead designer + signed/sealed drawings |
| Structural engineer | Foundations, frame, lateral system |
| Mechanical engineer | HVAC, controls |
| Electrical engineer | Power, lighting, low-voltage backbone |
| Plumbing engineer | Water, sanitary, storm, gas |

### Often required

| Discipline | When |
|---|---|
| Civil engineer | Site work, grading, utilities, stormwater |
| Fire protection engineer | Sprinkler, alarm, smoke control (often in MEP) |
| Landscape architect | Anything with site / planting / hardscape |
| Lighting designer | Civic, hospitality, retail, museum |
| Acoustical consultant | Education, healthcare, performing arts, multifamily, lab |
| AV / IT / low-voltage | Education, corporate, healthcare, civic |
| Security consultant | Civic, healthcare, federal, data centers |
| Code consultant | Complex code paths, alternate means, performance-based design |
| Sustainability / LEED / WELL | When certifying |
| Accessibility consultant | Anything beyond basic ADA — civic, public, complex existing buildings |
| Signage / wayfinding | Civic, healthcare, large education, corporate campus |
| FF&E designer | Hospitality, healthcare, education, corporate |
| Cost consultant / QS | Most projects > $5M; mandatory for public |
| Specifications writer | Often part of AOR; sometimes separate |

### Specialty (project-type specific)

| Discipline | Project type |
|---|---|
| Healthcare planner | Hospital, MOB, SNF, behavioral health |
| Lab planner | Wet lab, biotech, pharma, academic research |
| Kitchen consultant | Restaurant, hospitality, healthcare, K-12 |
| Theater / venue consultant | Performing arts, broadcast, sports |
| Vertical transportation | High-rise, hospital, public transit |
| Façade / building enclosure | Complex envelopes, high-rise, performance critical |
| Wind / CFD consultant | High-rise, complex urban site |
| Geotechnical engineer | Always; engaged by owner before SD |
| Survey | Always; engaged by owner before SD |
| Environmental / Phase I ESA | Almost always; required for financing |
| Traffic engineer | Large public-impact projects |
| Civic engagement / facilitation | Public-engaged projects |

## 3. Construction

| Stakeholder | When engaged | Notes |
|---|---|---|
| GC | DBB: bid post-CD. CMAR / IPD / PDB: pre-construction during design | Pre-con services include constructability, scheduling, estimating |
| CMAR | Pre-construction during DD, GMP at end of CD | Common for public, healthcare, education |
| Design-Build lead | Engaged at conceptual; carries design + construction | DOT, federal, some private |
| Key trade contractors | MEP, glazing, concrete, steel, elevator | Drive long-lead procurement; engage in DD if possible |
| Suppliers (long-lead) | Switchgear, AHUs, generators, custom glazing, elevators | Lead times in 2026: switchgear 60+ wk, AHUs 30-50 wk |
| Commissioning agent (CxA) | Engaged by owner before SD per LEED EAp1 / ASHRAE Guideline 0 | Independent of designer and contractor |
| Inspector of Record (IOR / DSA inspector) | California public projects (DSA, HCAI) | Owner-engaged, independent of GC |

## 4. Authority Having Jurisdiction (AHJ)

The NA AHJ landscape is dense. Always name the specific department.

### Universal

| Authority | Function |
|---|---|
| Building department / DOB | Permit, plan review, inspections |
| Fire marshal / FDNY (NYC) | Life safety, alarm, sprinkler review, occupancy load |
| Planning / zoning | Use, FAR, height, setback, sign-off on site plan |
| Public works / engineering | Right-of-way, curb cut, sidewalk, utilities tie-in |
| Health department | Food service, pools, child care, healthcare |

### Often applicable

| Authority | When |
|---|---|
| ADA / accessibility office | Public projects in many cities |
| Historic preservation (LPC in NYC, OHP in CA, SHPO state-level) | Historic district / landmark / federal undertaking |
| DOT (state or municipal) | New curb cut, traffic impact, signal change |
| Stormwater / sewer authority | Connection permit, on-site detention sizing |
| Environmental — state EPA or DEP/DEC | Wetlands, brownfield, air permit, asbestos |
| EPA Region | Brownfield, lead, federal-jurisdiction sites |
| US Army Corps of Engineers | Wetlands (Section 404), navigable waters |
| Coastal Commission (CA), DEC (NY) | Coastal projects |
| Tribal Historic Preservation Office | Tribal land, federal undertaking on tribal land |
| Utility companies | Service connection, easements (electric, gas, water, sewer, telecom, fiber) |
| FAA | Tall structures near airports (FAR Part 77) |

### Project-type-specific (US examples)

| Authority | Triggers |
|---|---|
| HCAI (CA, formerly OSHPD) | Hospitals, surgery centers, skilled nursing |
| DSA (CA) | K-12, community college |
| NYC SCA | NYC public school capital projects |
| GSA / PBS | Federal civilian buildings |
| USACE / NAVFAC / AFCEC | Federal military buildings |
| DOE | Federal energy/research |
| AABC / AHRI / NEBB | Commissioning standards (not AHJs but often referenced) |
| FDA (process spaces) | Pharma manufacturing |
| USDA | Food production |
| TSA | Airport secure areas |
| DOC / CMS | Hospital reimbursement (drives life-safety standards) |
| State agencies for prisons, courts, universities | Public sector specialty |

## 5. Public / community

| Stakeholder | When |
|---|---|
| Adjacent property owners | Variance, easement, construction impact |
| Community board / neighborhood council | Most urban infill projects |
| Business Improvement District (BID) | Commercial corridors |
| Advocacy groups | Affordable housing, environmental justice, accessibility, historic |
| Tribal nations | Federal undertaking; state-recognized projects |
| Press / PR | High-profile projects; manage proactively |
| Indigenous consultation | Required for federal undertaking under NHPA Section 106 |

---

## 6. Operations / post-occupancy

| Stakeholder | Why engage during design |
|---|---|
| Facility manager | FF&E, system selection, controls strategy, operations cost |
| IT / network | Wiring closets, riser sizing, AV infrastructure |
| Security operations | Camera coverage, access control, server location |
| Custodial / cleaning | Material selection, fixture cleanability |
| Food service operator | If commercial kitchen; equipment selection drives MEP |
| Parking operator | If commercial parking |
| Building engineer | Mechanical room access, equipment serviceability |
| Tenant fit-out coordinator | Multi-tenant office / retail |

## Project-type cross-reference (which categories are heavy)

| Project type | Heavy categories | Notes |
|---|---|---|
| Commercial office | Owner, Operations | Lighter community engagement; FM critical |
| Civic / public | Owner, AHJ, Community | Public hearings; multiple AHJ; long timelines |
| Healthcare | Owner, Design (specialty), AHJ (HCAI/state) | Heaviest design team; CxA mandatory |
| K-12 education | Owner, AHJ (school facilities, DSA in CA), Community | Public engagement, board approval |
| Higher education | Owner (multiple internal), Design (specialty for labs), Operations | Slow internal governance |
| Multifamily | Owner, AHJ, Community, Operations | Property management as future operator |
| Industrial / warehouse | Owner, Construction (long-lead trades) | Light design team, heavy procurement |
| Mixed-use | All categories | Most complex stakeholder map |
| Federal | Owner (GSA), AHJ (federal), Community light | Procurement-driven; specific federal standards |
