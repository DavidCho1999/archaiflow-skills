# Business

Every Business tool in one plugin: 23 skills, 2 agents and 6 commands for North American architecture practice.

## Skills

- **Document Export**: Render Markdown into Word, Excel, or PDF for transmittal
- **Agenda Builder**: Build the agenda around what has to be decided, not what to talk about
- **Client Translator**: Turn technical language into client-ready wording, and back
- **Contract Review**: Read an owner-drafted agreement for what it moves onto you
- **Dispute Advisor**: Find the next required step and notice deadline in a dispute
- **Fee Estimator**: Estimate a design fee four ways and split it by phase
- **Fee Tracker**: Track earned fee against billed, invoice by invoice
- **File Organizer**: Sort a messy folder into a taxonomy you approve first
- **Go / No-Go Review**: Score a pursuit before it costs you, on the things that actually predict
- **Insurance Advisor**: Recommend policy types, limits, and a wrap-up structure
- **Lessons Learned**: Record what a project taught you, and read it back next time
- **Meeting Notes**: Turn raw meeting notes into structured action items
- **Minutes Reader**: Read somebody else's minutes for what they recorded about you
- **Pipeline Tracker**: Track every pursuit from first whisper to won or lost, and what each cost
- **Post-Occupancy Evaluation**: Find out how the building is actually used, and tell someone
- **Project Tracker**: Keep issues, decisions, risks, and action items in one dated log
- **RFP Response Builder**: Build a response that answers what was asked, in their order
- **SF330 Builder**: Assemble an SF330 with the project sheets that actually match the scope
- **Stakeholder Map**: Map who decides what, and who talks to whom
- **Start the Project**: Settle what has to be decided now, and what can wait
- **Subconsultant Agreement Review**: Check that your subconsultant agreements match what you promised the owner
- **Thread Reader**: Read an email or message thread for what was actually decided
- **Utilization Tracker**: Track hours against fee by phase, and see the overrun while it is small

## Agents

- **Architect of Record**: A licensed architect's read on what you are about to seal
- **Construction Attorney**: A construction lawyer's read on a contract or claim

## Commands

- **Draft Additional Services**: Draft an additional services request before the work is done, not after
- **Draft Email**: Write the project email, and check whether it should be an email at all
- **Draft Proposal**: Draft a fee proposal that says what is not included
- **Explain AIA**: Read a contract clause from all three sides
- **Explain COI**: Explain a certificate of insurance and what it does not prove
- **Generate Weekly Report**: Generate a weekly project status report

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **practice-contracts**.

In Claude Code:

```
/plugin install practice-contracts --marketplace DavidCho1999/archaiflow-skills
```

Browse and read each one at https://archaiflow.com/templates/practice-contracts.
