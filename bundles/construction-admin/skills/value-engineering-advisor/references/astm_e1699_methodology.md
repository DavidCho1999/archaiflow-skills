# ASTM E1699 — VE Job Plan (Reference Outline)

Outline of the published industry-standard Value Analysis methodology for buildings. Use this reference to anchor recommendations to the published Job Plan rather than presenting this skill's six-axis classification as the standard.

ASTM E1699 (Standard Practice for Performing Value Analysis (VA) of Buildings and Building Systems) is the most-cited published reference. SAVE International's "Value Methodology Standard" parallels it. CMAA preconstruction services scope references VE workshops as part of preconstruction CM at-risk service.

**Verify edition with the ASTM publisher before citing a section.** Section numbers may shift across reissues.

---

## The six-phase Job Plan

ASTM E1699 structures Value Analysis as six sequential phases (referred to as the "Job Plan"). Most VE workshops in NA practice follow some variant of this sequence even when not explicitly cited.

### 1. Information Phase

- Gather project documents: latest drawings, current spec, latest budget / cost estimate, OPR, schedule, owner constraints, code anchors, certification commitments.
- Identify the cost gap (current estimate vs. budget) and the items driving it.
- Identify owner-stated priorities (must-have, nice-to-have, out-of-scope).

### 2. Function Analysis Phase

- For each high-cost item, identify the function it serves (verb + noun, e.g., "resist water" / "support load" / "convey people").
- Distinguish basic functions (must perform) from secondary functions (enhance, support).
- Build a Function Analysis System Technique (FAST) diagram if useful.

### 3. Creative Phase

- Generate alternative ways to perform each function.
- No judgment in this phase — quantity over quality.

### 4. Evaluation Phase

- Evaluate each alternative against function, cost, schedule, and owner priorities.
- This is where this skill's six-axis classification (`ve_assessment_axes.md`) lives — it is a structured evaluation rubric for Phase 4.

### 5. Development Phase

- Develop the surviving alternatives into specific proposals: spec / drawing changes, cost impact, schedule impact, lifecycle impact, performance impact.
- Each proposal includes: description, current vs. proposed, savings, advantages, disadvantages, recommendation.

### 6. Presentation Phase

- Present proposals to the owner / design team / CM-GC at a VE workshop or OAC meeting.
- Owner / AOR makes the accept / alternate / reject call.
- Accepted items roll into AIA G701 (CO), G710 (ASI), or G714 (CCD) per the contract — see `aia_contracts_quick_ref.md`.

---

## Where this skill sits in the Job Plan

This skill's primary role is **Phase 4 (Evaluation)** and **Phase 6 (Presentation)** support:

- Phase 4 — apply the six-axis classification to each proposed VE item.
- Phase 6 — produce the recommendation memo that the AOR / owner takes into the workshop.

This skill does **not** replace Phases 1–3 (Information, Function, Creative). Those are upstream owner / AOR / CM responsibilities; this skill consumes their output.

## Anti-pattern

Do not present this skill's six-axis classification as ASTM E1699 or as SAVE International methodology. The six-axis framework is **synthesized for this skill** to support Phase 4 (Evaluation). Cite ASTM E1699 / SAVE separately as the methodology anchor; cite the six-axis framework as a working evaluation rubric.
