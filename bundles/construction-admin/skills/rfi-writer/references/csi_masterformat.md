# CSI MasterFormat 2020 — Common Sections

> CSI MasterFormat is updated periodically. **2020 is the current published edition**; verify with [csiresources.org](https://www.csiresources.org/) if a newer edition has shipped. Codes themselves are stable across editions; only category labels and a few new sections (typically in emerging-tech divisions) change between editions. When in doubt, the section number cited in the project's specifications takes precedence over this reference.

Cite specifications using these codes. Do not invent codes — if a needed section is not in this list, ask the user.
