# Documents & Construction

Every Documents & Construction tool in one plugin: 31 skills, 7 agents and 17 commands for North American architecture practice.

## Skills

- **Bid Review**: Review contractor bids for scope, exclusions, and terms before award
- **Change Order Review**: Work through a change's scope, cost, and time before it is signed
- **Change Order Tracker**: Track every change from first mention to executed, including the ones that stall
- **Closeout Check**: Track closeout deliverables from the spec book to handover
- **Constructability Review**: Read a document set through a builder's eyes
- **Coordination Log**: Track a conflict until both sets show the same answer
- **Cost Reader**: Read any cost document for what it excludes and what it assumed
- **Delay Triage**: Work out whose delay this is before anyone writes a letter
- **Doc Reader**: Read and interpret a specification, report, or contract PDF
- **Document Diff**: Compare two versions of a document and find what nobody mentioned
- **Drawing Checklist**: Get a drawing-set checklist for the phase you are in
- **Drawing Diff**: See what changed between two drawing revisions
- **Drawing Log**: Track every sheet's revision and issue history in one log
- **Drawing Reader**: Read and interpret an architectural drawing PDF
- **Drawing Bookmarks**: Bookmark a flat drawing-set PDF and index its sheets
- **Drawing Standards Audit**: Sweep a set for the conventions that make it readable, not for what it shows
- **Markup Reader**: Read a marked-up drawing and turn it into a list somebody can act on
- **Model Health Audit**: Audit a BIM model for the habits that make it slow, wrong, or unshareable
- **Photo Reader**: Read a photograph for what it shows and what it cannot show
- **Punch List**: Keep a punch list with location, trade, owner, and status per item
- **RFI Tracker**: Keep the RFI log, and watch the pattern the individual answers hide
- **RFI Writer**: Turn a site question into a filed, formal RFI
- **Schedule Builder**: Build a door, window, finish, or room schedule that the drawings can survive
- **Schedule Extractor**: Pull door, window, and finish schedules out of a PDF into CSV
- **Schedule Review**: Read a contractor's schedule for what it assumes about you
- **Set Reader**: Read a whole drawing set and say what kind of set it is
- **Spec Outline Builder**: Build the section list this project needs from the drawings it has
- **Spec Review**: Audit a spec book for gaps and drawing coordination
- **Submittal Log**: Build a submittal log from the spec book
- **Submittal Review**: Review a shop drawing or product data against the documents
- **Value Engineering**: Sort a cost-cutting list into accept, alternate, and block

## Agents

- **BIM Architect**: A BIM lead's read on a model, family, or execution plan
- **Project Search**: Find an answer in your own files, with a citation
- **Owner Representative**: Reads your recommendation the way the person paying for it will
- **Senior Contractor**: A senior builder's gut-check on a package before it goes out
- **Senior Cost Estimator**: An estimator's read on what a number is really carrying, and what it is not
- **Senior Scheduler**: A planner's read on what actually controls the date, and who controls it
- **Senior Specifications Consultant**: A spec writer on how the words read to someone looking for room to move

## Commands

- **Create Site Visit Report**: Write a field observation report with photos
- **Create Transmittal**: Make a cover sheet for a document package
- **Draft ASI**: Instruct the contractor without changing cost or time
- **Draft Bulletin**: Write a cover letter for a bulletin or addendum
- **Draft Callout**: Write the text inside a drawing callout
- **Draft CCD**: Direct a change before cost and time are agreed
- **Draft General Note**: Write a general note that says something, and put it on the right sheet
- **Draft Payment Application**: Draft a contractor payment application
- **Draft RFI Response**: Answer an RFI without giving away scope, cost, or time
- **Draft Spec Snippet**: Write a product paragraph for a spec section
- **Draft Substantial Completion**: Draft the certificate, and check whether the date it claims is real
- **Explain Bid**: Separate real costs from risk-shifting in bid language
- **Explain Drawing**: Explain a detail, callout, or section in plain English
- **Explain Spec**: Explain a specification section in plain English
- **Explain Stamp**: Explain what a submittal stamp commits you to
- **Lookup Cost**: Look up a cost-per-square-foot benchmark, quoted with its source
- **Lookup CSI**: Find the spec section number for a product or scope

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **construction-admin**.

In Claude Code:

```
/plugin install construction-admin --marketplace DavidCho1999/archaiflow-skills
```

Browse and read each one at https://archaiflow.com/templates/construction-admin.
