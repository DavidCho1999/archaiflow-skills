# PHIUS+ 2021 — Methodology (Targets Are Project-Specific, Not Bundled)

> **PHIUS+ 2021 climate-specific targets are project-specific and derived per-project via the PHIUS Source Zero portal (or PHIUS-WUFI workflow). Bundled metro→target tables would mislead — all earlier sample values have been removed (see audit 2026-05-09).**

> **Source**: PHIUS+ 2021 Certification Guidebook (PHIUS, North American Passive House Institute). Publicly summarized at https://www.phius.org/phius-source-zero. Per-project targets are generated by PHIUS via its Source Zero portal (free with PHIUS account).

---

## Why no bundled targets

Per audit 2026-05-09 (`feedback_standards_verification.md`), bundling fabricated targets next to verified PHI criteria created a foot-gun where users would paste sample values into real scorecards. The honest path is to direct each project to the PHIUS portal.

Earlier revisions of this file included a 12-metros × 4-metrics "sample" table (Phoenix, Miami, Houston, Atlanta, Los Angeles, Charlotte, Washington DC, Chicago, Boston, Minneapolis, Anchorage, Seattle — annual heating, annual cooling+dehum, peak heating, peak cooling). Those 48 cells were unsourced — model-recall numbers presented in tabular form next to verified PHI criteria. They have been removed in full and are not being replaced. The right shape for these values is a per-project portal export, not a metro lookup table.

---

## How PHIUS+ 2021 differs from PHI

PHIUS+ 2021 generates **climate-specific** targets (per project) using building geometry + use type + occupancy, instead of PHI's fixed metric thresholds. The targets are derived from PHIUS's Source Zero methodology, which back-solves the energy budget needed to achieve net-zero source energy (after typical on-site renewable installation) for the project's specific climate.

The targets vary per project — they cannot be tabulated as static "targets" by metro because two projects in the same metro with different geometry, occupancy, or use type will receive different target values from the portal.

## Tracked metrics (PHIUS+ 2021)

These are the metrics PHIUS+ 2021 tracks — units and direction are fixed; target values are not.

| Metric | Direction | Units |
|--------|-----------|-------|
| Annual heating demand | lower is better | kBtu/sf·yr (ICFA) |
| Annual cooling+dehum demand | lower is better | kBtu/sf·yr (ICFA) |
| Source energy | lower is better | kBtu/person·yr (PHIUS+ 2021 uses per-occupant; some references quote per-sf for older versions) |
| Peak heating load | lower is better | Btu/h·ft² (ICFA) |
| Peak cooling load | lower is better | Btu/h·ft² (ICFA) |
| Air leakage | lower is better | CFM50/sf envelope (≤ 0.06 for residential, ≤ 0.08 for non-residential) |
| Limited overheating frequency | lower is better | % hours over upper comfort threshold (target ≤ 10) |

> Note: PHIUS air-leakage target is a fixed envelope-area-normalized value (not climate-specific), unlike PHI's ACH50. Overheating threshold is also a fixed limit.

## How to derive PHIUS+ 2021 targets for your project

1. **Determine ASHRAE 169-2021 climate zone for the project location.** Use the bundled `climate-zone-mapper` skill or look up directly in ASHRAE 169-2021 Table A-1 / A-2. For US projects, the project ZIP code maps to a climate zone via that table.
2. **Gather project inputs:**
   - Project address / ZIP
   - Conditioned floor area (ICFA — Interior Conditioned Floor Area, sf)
   - Number of occupants (project-specific, not assumed)
   - Energy use type / building type (single-family, multifamily, mixed-use, etc.)
3. **Run the PHIUS Source Zero calculator at https://www.phius.org/phius-source-zero** (free PHIUS account required). Input the values from step 2.
4. **Outputs** — the portal returns project-specific target intensities for:
   - Annual heating demand (kBtu/sf·yr ICFA)
   - Annual cooling+dehum demand (kBtu/sf·yr ICFA)
   - Source energy (kBtu/person·yr)
   - Peak heating load (Btu/h·ft² ICFA)
   - Peak cooling load (Btu/h·ft² ICFA)
   - (Air leakage and overheating thresholds are fixed PHIUS+ 2021 values, not portal-derived.)
5. **The output is project-specific — do not generalize across metros.** Two projects in the same ZIP with different ICFA / occupancy / use type will receive different targets. Save the portal export (CSV or PDF) as the `Source` for the `Target` column in your scorecard.

Production certification requires PHIUS-certified energy modeler review of WUFI Passive output against the portal targets. The skill's role is to compare actuals to those targets — not to generate the targets.

- The methodology for deriving per-project targets via the PHIUS Source Zero portal.

This file does NOT cover:

- **PHIUS+ Source Zero overlay** (net-source-zero on top of PHIUS+ 2021).

For accurate project-level targets, the user must fetch from https://www.phius.org/phius-source-zero (free PHIUS account required).
