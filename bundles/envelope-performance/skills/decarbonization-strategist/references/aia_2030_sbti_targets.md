# AIA 2030 Commitment + SBTi Buildings Targets

Voluntary frameworks that drive owner / firm decarbonization commitments. Cite from this file rather than recalling target percentages from memory — frameworks ratchet annually.

---

## AIA 2030 Commitment

**What:** Pledge by AIA member firms (and signatory non-member firms) to achieve carbon-neutral operations on new + major-renovation projects by 2030.

**Targets (ratcheted):**

- Originally 50% reduction in operational carbon (vs. regional baseline) by 2010, ratcheting to net-zero by 2030.
- Annual reporting requirement for signatories.

**Reporting platform:** AIA Design Data Exchange (DDx).

**Signatory annual report:** Each signatory firm reports portfolio EUI / operational carbon / renewables / embodied carbon (where modeled) annually.

**How this skill uses 2030:** When the owner's project is for an AIA 2030 signatory firm, the firm has a portfolio-level reporting obligation that the project must contribute to. The roadmap memo references the firm's current target.

**Verify current target ratchet** with AIA 2030 program documentation.

## SE 2050

**What:** Structural-engineering parallel to AIA 2030; pledge by SE firms to achieve net-zero embodied carbon on structural systems by 2050.

**Reporting platform:** SE 2050 Database.

**How this skill uses SE 2050:** When the structural EOR is a signatory, the roadmap embodied-carbon section coordinates with the SE's reporting obligation.

## MEP 2040

**What:** MEP-engineering parallel; embodied + operational carbon for MEP systems.

**Reporting platform:** MEP 2040 Database (in development).

## SBTi (Science-Based Targets initiative) — Buildings

**What:** Sector-specific science-based targets for buildings, providing a carbon-budget pathway for buildings consistent with limiting warming to 1.5°C.

**Components:**

- Whole-building operational carbon: kgCO2e/m² (or kgCO2e/sf) trajectory by year by building type.
- Embodied carbon: per-project LCA targets at A1–A5 scope.

**Owner commitment:** Companies commit to SBTi reductions across scope 1, 2, and 3 emissions; building portfolios fall under scope 1 (operational, owned), scope 2 (electricity), and scope 3 (capital goods including embodied).

**How this skill uses SBTi:** When the owner is an SBTi-committed company (corporate real-estate portfolios, REITs, hospitality), the roadmap aligns building-level carbon trajectory with the corporate trajectory.

**Verify current targets** with SBTi sectoral guidance.

## Architecture 2030 Challenge / Roadmap to Zero

**What:** Origin of the 2030 net-zero target; broader campaign than AIA Commitment.

**Components:**

- 2030 Challenge — buildings + districts.
- Embodied Carbon Action Plan — embodied carbon ratchet.
- ZERO Code — new buildings + major renovations design to zero net energy.

**How this skill uses A2030:** Reference framework + technical guidance source.

## WGBC Net Zero Carbon Buildings Commitment

**What:** Owner pledge framework — companies pledge net-zero operational carbon on owned + occupied buildings.

**How this skill uses:** Owner-commitment context.

## How target frameworks interact with mandates

| Framework | Owner-side commitment | Mandate equivalent |
|-----------|----------------------|---------------------|
| AIA 2030 | Architect-firm voluntary | None directly |
| SE 2050 | Structural-firm voluntary | None directly |
| MEP 2040 | MEP-firm voluntary | None directly |
| SBTi | Company portfolio pledge | None directly; informs owner-side capex priority |
| WGBC NZCBC | Company portfolio pledge | None directly |
| LL97 / BERDO / BEPS / Title 24 | Building-specific mandate | Mandatory; fines for non-compliance |

**Key distinction:** Voluntary frameworks set ambition; mandates set compliance floors. A sophisticated owner roadmap satisfies the mandate floor AND advances toward the voluntary target.

---

## How this skill cites target frameworks in the roadmap memo

- **Owner is signatory** to one of the frameworks — the roadmap targets align with the framework's current ratchet, with explicit confirmation that the architect / SE / MEP firm is also signatory (so the project contributes to firm reporting).
- **Owner is not signatory** but project pursues a comparable target — the roadmap names the framework benchmark for context.
- **Owner is in mandate-only mode** — the roadmap targets the mandate floor; voluntary frameworks are referenced as "available next-tier benchmarks for consideration."

The choice influences the aggressiveness of the pathway in `phasing_patterns.md`.
