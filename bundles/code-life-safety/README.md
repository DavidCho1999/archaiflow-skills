# Code & Zoning

Every Code & Zoning tool in one plugin: 31 skills, 9 agents and 18 commands for North American architecture practice.

## Skills

- **Accessibility Tracker**: Build an accessibility compliance checklist for a project
- **Alternative Means Builder**: Make the case that an alternative meets the intent of a rule you cannot meet
- **Applicability Check**: Work out whether a requirement applies to you before reading it
- **Cite Check**: Check whether a citation someone gave you is real and current
- **Civil Drawing Review**: Check the civil set against the architectural, in both directions
- **Climate Zone Mapper**: Record a site's climate zone and its envelope requirements
- **Code Analysis**: Assemble the code analysis block for a cover sheet
- **Code Analysis Reader**: Read somebody else's code analysis for what it assumed and never showed
- **Code Compliance Review**: Audit a plan across eight egress and accessibility axes
- **Code Reader**: Turn a code section into the requirements it actually contains
- **Compliance Check**: Hold a drawing against code text you paste, item by item
- **Design Accessible Restroom**: Lay out an accessible restroom from clearances that overlap, not a checklist
- **Design Egress**: Verify exit counts, widths, separation, and travel distance
- **Design Fire Barrier**: Follow a rated assembly from floor to deck and find where the rating stops
- **Design Occupancy Load**: Compute occupant load by use group and by space
- **Design Parking Layout**: Lay out parking around the bay, the aisle, and the ramp
- **Design Stair**: Check a stair flight against the limits your code sets
- **Entitlement Tracker**: Track a discretionary approval from application through hearings to conditions
- **Geotech Report Review**: Read a soils report for what it commits you to
- **Jurisdiction Profile**: Record your code's limits once, with citations, and reuse them
- **NYC Zoning Lookup**: Answer NYC zoning questions with citations
- **Permit Tracker**: Keep one dated record of every permit, review and inspection a project needs
- **Plan Check Response Builder**: Turn a reviewer's comments into a matrix that answers each one on the record
- **Seismic Lookup**: Record a site's seismic design parameters and where each came from
- **Site Access Study**: Work out how vehicles, services, and fire access reach the site
- **Standard Reader**: Read a referenced standard for what it covers and what it does not
- **Submission Reader**: Read what an authority sent back and say what it actually requires
- **Survey Review**: Read a survey for what it does not say, before you design against it
- **Variance Request Builder**: Build the case for a variance against the findings the board has to make
- **Wind Snow Lookup**: Assemble the site hazard criteria a design needs
- **Zoning Summary**: Turn a parcel lookup into a zoning summary for early design

## Agents

- **Accessibility Specialist**: An accessibility read on the journey, not the checklist of compliant items
- **Landscape Architect**: A landscape architect's read on site, grading, and planting
- **Permit Expeditor**: Plans the route through the building department, and unsticks a stalled one
- **Senior Civil Engineer**: A senior civil engineer's gut-check on site and drainage
- **Senior Code Consultant**: A code consultant's read on which compliance path this building should take
- **Senior Geotechnical Engineer**: A geotechnical engineer's gut-check on a soils report
- **Senior Plan Examiner**: Reads your set the way the person who can reject it will read it
- **Senior Traffic Engineer**: A traffic engineer on access, trips, and what the study will conclude
- **Urban Designer**: An urban designer's read on a master plan or public realm

## Commands

- **Count Loading Berths**: Work out required loading berths from the table you supply
- **Count Plumbing Fixtures**: Work out required fixture counts from the table you supply
- **Draft Letter**: Write a letter to the building department
- **Explain Code**: Put a code section in plain English
- **Explain Easement**: Explain what an easement on your survey does to what you can build
- **Explain Soils**: Explain a geotechnical recommendation in plain English
- **Explain Zoning**: Put a zoning clause in plain English for your site
- **Lookup Flood Zone**: Find a parcel's flood zone and base flood elevation, with its source
- **Test ADA**: Math-check one accessibility clearance against the source
- **Test Allowable Area**: Check a building's allowable area
- **Test Egress**: Check one egress question - pass, fail, or marginal
- **Test FAR**: Check floor area ratio, coverage, setback, and height
- **Test Fire Rating**: Check the required hourly rating for an element
- **Test Occupant Load**: Compute occupant load when you already have the table row
- **Test Open Space**: Check provided open space against what the district requires
- **Test Parking**: Check required parking count and accessible spaces
- **Test Ramp**: Check a ramp's slope, landings, and handrails
- **Test Stair**: Check stair geometry when you already have the code text

## Install

In the Claude app: Customize > Plugins > Add marketplace, paste `DavidCho1999/archaiflow-skills`, then install **code-life-safety**.

In Claude Code:

```
/plugin install code-life-safety --marketplace DavidCho1999/archaiflow-skills
```

Browse and read each one at https://archaiflow.com/templates/code-life-safety.
